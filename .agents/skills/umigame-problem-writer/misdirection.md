# 意味誤誘導型（misdirection）の工程 3・4

SKILL.md の工程 3・4 の位置に差し込んで使う分冊。意味誤誘導型は「言い換えで誤認させ、正させてカタルシスを生む」型で、**問題文の語そのもの**（慣用句・多義語・定型の言い回し）が誤読を強制することがコア。2026-09-20 時点で通過 7 問（U01・U11〜U16）はすべてこの型。

## 工程 3M: 言い方を変える → コア宣言

- 連想の 1 つを**具体化**（手を握る → アイドルの手を握る）または**抽象化**（麺を打つ → 打たれたもの）して、別の状況へ誤認させられる言い方を探す
- 見つかったら**コア宣言**を 1 文で書く。様式は固定:

  ```
  コア: 「<問題文中の語・状況>」を <誤認させる読み> と読ませる → 実際は <反転後の事実>
  ```

- **コア検査（misdirection 固有。SKILL.md 工程 3 の共通検査と合わせてすべて Yes でなければ戻る）**:
  - **誤読を問題文の語が強制しているか**。慣用句（影が薄い・凍りつく）・多義語（打つ・落とす・駅・卵）・定型の言い回しなら読者は必ずその読みに乗る。「時計台の下に立つ = 待ち合わせ」のように読者が自分で補う連想は、問題文の別の語（「誰も来たことはない」）で簡単に降りられるのでコアにならない（21-4a-2 の U11 初稿がこの失敗。**語そのものに仕掛けがない案は、状況が不思議でも捨てる**）
  - **誤読が語の第一義か**。「滑る」のように第一義が反転後（氷で滑る）にある語は、誤読（試験に滑る）が強制されない（21-4a-3 U16 の巡で捨てた案）
  - **定型表現は全体で使っているか**。「タネも仕掛けもございません」は全体でこそ誤読を強制し、一部だけの切り出し（「タネはありません」）では読者が乗り切らない（21-4a-2 U14 の取り下げ案）
  - **反転後が具体的な仕組み・事実に着地しているか**。通過 7 問はいずれも「語の仕掛け + 仕組み」（レントゲンの影 / 救急車の前面表記 / ひな人形 / タイムカプセル / 職人の卵 / 配信の遅延 / 氷鬼のルール）。反転後が商品の宣伝・営業の工夫・ありふれた習慣だと、語の仕掛けがあってもカタルシスが小さい

## 工程 4M: 不思議にする

- 誤認先の常識を **3 つ以上**列挙する（例: 握手会 → 「客が金を払う」「並ぶ」「一瞬で終わる」）
- そのうち 1 つの**逆**を問題文に足して状況を矛盾させる（握手して大金を得た）。足すのは 1 つで足りる
- **足す逆は、誤認の読みのままでも「ありえなくはない」範囲に留める**。誤認の読みで物理的に不可能な文（「卵がパンを焼いている」「卵を十年間育てた」）を問題文に置くと、読者は一瞬で語の仕掛け（比喩・多義）に気づいて誤読が壊れ、コアが効かなくなる（21-4a-2 U14 3 案目初稿の失敗。「焼くことも割ることもしないのに、パンがおいしいのはこの卵のおかげだと自慢する」のように、誤認の読みのまま不思議に見える形へ言い換える。外した不可能文の情報は真相・確定事実シートへ回す）。工程 4.5 の検査「誤読が最後まで維持されるか」はこの観点でも見る
- 問題文の草案を書き、「どういうこと？」で締める → SKILL.md 工程 4.5 へ

## 失敗パターン（misdirection 固有）

- **状況だけで持たせる**（21-4a-2 U11）: 語に仕掛けがなく「不思議な習慣」を意外な動機で説明するだけの問題。動機を現実的にすると平凡になり、意外にすると現実離れする。コア宣言の「〜と読ませる」の部分に慣用句・多義語・定型表現が入っていなければこの型（そういう案は story 型として組み直せるか見る）
- **因果の直結**（21-4a-2 U11）: 「鏡文字で書いた → 早く着ける」のように、仕掛けと結果を「おかげで」で直結し、間の場面を置かない。読者に足場がなく意味不明に見える。SKILL.md 工程 4 の受け皿を 1 つ置く
- **売り文句・宣伝への反転**（21-4a-2 U14）: 「タネはありません = 手品の口上 → 種なしスイカの売り文句」はコア検査を自己申告 Yes で通ったが、人間ゲートで「コアが弱い」と取り下げ。落差と強制の 2 項目は、自分の Yes を疑って反転を一文で声に出してから判定する
- **不可能文で誤読が自壊**（21-4a-2 U14）: 工程 4M の 3 項目
- **正解が一つに定まらない仕掛け**（21-4a-3 U16 の巡で捨てた「だるまさんがころんだ」案）: 「言葉で全員が凍りつく」は「はいチーズ」でも成立する。反転後の事実が複数あるなら、問題文に 1 つへ絞る材料を置くか捨てる
