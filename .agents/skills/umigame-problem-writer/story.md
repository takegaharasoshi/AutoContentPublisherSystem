# 物語復元型（story）の工程 3・4 — 物語先行方式

SKILL.md の工程 3・4 の位置に差し込んで使う分冊。物語復元型は**隠蔽**の型で、**完結した物語 A→B→C から B を抜いて A→C を出す**。参照記事のとおり、この型に**ミスリードは要件ではない**。カタルシスは「隠された部分を復元できた」こと自体から来る。だから**面白いのは物語であって、切り出しはその面白さを問題の形に変える作業**にすぎない。物語が面白くなければ、どう切り出しても面白くならない。

**経緯（2026-09-22 再設計・ユーザー決定）**: 旧 story.md は「読者が B を誤って補完する（誤った補完 X）」をコアの必須要件にし、検査軸も「誤読の強制・役割の逆転か皮肉・前提を壊す反転」と意味誤誘導型のままだった。参照記事は「モチーフのミスリードを起点にする作り方では物語復元型の作問はできない」と明記しており、この構造矛盾が 21-4a-3 U20 の 5 候補連続 NG（探索が「物語」ではなく「身近な仕組みトリック探し」に偏った）で表面化した。再設計では**物語先行方式へ一本化**する。旧方式で通過した U17〜U19（仕組みの反転）は削除済みで、以後この分冊では扱わない。**仕組みトリック系の案が出たら、U18 の前例どおり misdirection 側で語の仕掛けが立つかで判断**し、story として通そうとしない。

**通過の実績（2026-09-23・U20「間違えたのは誰か」= 新方式の初通過）**: 娘が毎晩同じ箇所で間違える練習曲を父が間違いごと覚え、発表会で講師の完璧な模範演奏を「間違えた」と思い、隣の妻が笑った。**通った形**: ① 皮肉が笑いとして落ちる（毎晩聞いていた愛情が間違いを正解として刷り込んだ。感動話の型に乗らない）② 最初の連想（音楽の専門家で厳しい / 別の編曲を知っていた / 勘違い）が真相に届かず、質問で否定されたあと消去法で「その曲をどこで覚えたか」へ向かう動線がある ③ B が比喩・定番の筋に当たらない。**同じ巡で NG になった 2 本の条件**: 物語 2「早すぎた拍手」（娘が家で必ず止まる小節を本番で越えた瞬間に父が途中で拍手）= B の素材〔家で練習を聞いていた父〕が物語 1 と重複し、演奏中の拍手は「感激して」で感情が直行して難易度 3 止まり / 物語 3「ピアノへのお辞儀」（手放したピアノと発表会の舞台で再会）= 「手放した物との再会」という定番の筋で、note の創作に同じ筋があり、現実性も「同じ町のホールに買われる偶然」で弱い。2 巡目は 1 抽選で 3 本書けて 1 本が通った（旧方式は 5 候補連続 NG・1 巡目は定番の筋で 3 本 NG）。**U22「二時間かけて通う歯医者」（2026-09-23・3 巡目で通過）**: 育った家が改装されて歯医者になり、男が検診を口実に通う。1〜2 巡目の 5 本が「簡単」で NG になったあと、「B が場面の外の過去にある物語だけを残す」「疑いで直行を認めた案は提示しない」で約 12 案を絞って通った。最初の連想が人とサービス（先生・腕・費用）に向き、否定のあと「場所」→「建物」と二段で届く形。**U23「おじいさんのお釣り」（2026-09-23・1 巡目で通過）**: 祖父が毎朝、店先の自販機のお釣り口に十円玉を入れ、孫がそれを集めて祖父の誕生日にその自販機で缶コーヒーを買う。B が場面の外（誕生日より前の毎朝）にあり、こっそりの善意がお金ごと一周して本人に戻る形（U20〜U22 と構造が重ならない）。提示前に「場面の中の物が B になる案」と定番の筋を捨て、2 本に絞った巡で通った。以後の通過で知見が増えたら書き換える。

**要件から外したもの（あれば加点、なくても可）**: 誤った補完 X の強制 / 役割の逆転か行為の皮肉 / 読者の前提を壊す反転 / B が「仕組み」であること。
**残したもの**: B は出来事・事情・事実であって気持ちだけではない / 不思議は 1 つ / 身近な題材・小中学校の知識 / 最初の連想が真相に直行しない（難易度の検査として）/ B の行為の必然性。**死や別れの題材は story では可**（2026-09-22 ユーザー決定。物語の面白さを優先する）。

## 工程 1S・2S 前段: 連想の向き

- 工程 1 のランダム語はそのまま使う（オリジナル性の担保）。story では「状況・場所・出来事を持つ語」に寄せてよい
- 工程 2 の連想は、**仕組み・性質ではなく「その語のまわりで人に起きる出来事・事情・感情の動き」**へ向ける。観点: 誰がそれに関わるか / その人にどんな事情があるか / そこでどんな行き違い・偶然・約束・勘違いが起きるか / 前と後で人の気持ちがどう変わるか / その語をめぐって人が「らしくない行動」をするのはどんなときか
- 「そうなっている仕組み」「時間が経つと変わるもの」を書き出すのは可だが、それだけで物語にしない（仕組みが主役の案は工程 2S の物語ゲートで落ちる）

## 工程 2S: 物語を書く → 物語ゲート

1. **5〜7 文の完結した物語を先に書く**。含めるもの: 誰が（男・女を既定にする。属性は必要なときだけ）/ どんな事情で / 何をして / 何が起きて / どうなった / その結果の気持ちや反応。**問題にすることをまだ考えない**。読み物として閉じた話にする
2. **物語を 2〜3 本書く**（同じモチーフから、または再抽選して）。1 本だけ書いて切り出しに進まない（U20 の巡は 1 候補ずつ出して 5 連続 NG になった。物語は短いので複数書く方が安い）
3. **物語ゲート（物語単体の面白さ。各本について判定を書く）**
   - **話したくなるか**: 問題にしなくても、誰かに「こんなことがあってね」と話したい話か。聞いた人が「へえ」「うわ」「ああ、そうか」のどれかを言うか。どれも言わない話は捨てる
   - **面白さの要素が 1 つ以上あるか**: 意外な事情（見えていた行動の裏に別の事情があった）/ 感情の反転（悲しいと思った出来事が嬉しい出来事だった、またはその逆）/ 偶然の妙（無関係に見えた 2 つがつながった）/ 小さな善意や皮肉（誰かのための行動が別の形で現れた・良かれと思った行動が裏目に出た）
   - **現実性**: 日常の出来事・小中学校の知識・架空設定なし。「その人は本当にそれを、その事情でするか」と 1 回問う（SKILL.md 工程 6 と同じ。物語の段階で問う方が早い）
   - **流通した比喩・定番の筋ではないか**（U20 1 巡目の知見）: 隠すことになる出来事を一言で言ったとき、それが慣用的な比喩（「機嫌 = 天気」「心の天気」）や物語の型として定着した筋（「最悪の日が実は出会いの日」「亡き人の日記に自分への言葉」）に当たるなら、問題にしたとき最初の連想が真相に直行する。**Web 照合は投稿問題しか引けず、比喩や筋の定着は照合では落ちない**ので、ここで自分に問う。定着した筋に乗る物語は、筋を変えるか捨てる
   - **自分の Yes を疑う**: 各項目に「疑い: 〜」を一行添える。特に「自分が仕組みを知っているから面白く感じているだけではないか」と「**その筋を既にどこかで聞いたことがないか**（エッセイ・SNS の小話・ドラマの定番）」を疑う（旧方式の失敗の入口 / U20 1 巡目で AI の物語ゲートは 2 本を通したがユーザーは 2 本とも「簡単・面白くない」。AI の「へえ」は甘い前提で書く）
4. **自分の疑いに「直行する」と書いた本は提示しない**（U22 の巡: 1 巡目・2 巡目の 5 本すべてが「簡単」で NG。うち 4 本は提示前の疑い欄に「最初の連想が真相に早く届く」と自分で書いていた）。疑いで直行を認めたら、切り出しを変えるか物語を捨て、2〜3 本がそろうまで書き足す。**難しさの観察**（通過 2 本と U22 の NG 5 本の比較）: 通過した U20・U21 は B が**問題の場面とは別の時間・場所の出来事**（毎晩の家での練習 / 去年の種飛ばし）で、問題文の場面に B の気配がない。NG の 5 本は B が**場面の中の物・人・その場の事情**（端末・指輪・犬・声）で、C を読むと B のカテゴリがその場で見えた
5. ゲートを通った物語だけを工程 3S に回す。全部落ちたらモチーフ（工程 1）に戻る（戻った回数と捨てた物語は作問ログに残す）

## 工程 3S: 切り出しの設計 → コア宣言

物語のどこを隠すかがコア。「引っ掛けてやろう」という悪意の置き場は、**言葉ではなく欠落**にある。

1. **隠す候補を列挙する**: 物語の各文について「これを隠したら残りはどう見えるか」を一行ずつ書く。隠すのは 1 か所（B）。B は**出来事・事情・事実**（誰が何をした / 何があった / 何を知っていた）で、「〜したかった」「〜のため」という**気持ちだけの B は不可**（動機は、その動機が生んだ具体的な出来事・事実まで掘って B にする。U15 の巡の「防犯のため」「思い出のため」がこの失敗）
2. **B を選ぶ基準**: 「どこを隠すと A→C が最も不可解に見え、復元したときの納得が最大か」。次の 2 軸で候補を比べる
   - **切り出し後の不可解さ**: B を隠した A→C が、常識と矛盾して見えるか（「ふつうはそうしない・そうならない」が 1 つ立つか）。説明の候補が読者の頭にいくつか浮かぶが、どれも決め手にならない状態が理想。**最初の連想が真相に直行しないか**（C を読んで一瞬で思いつく説明がそのまま B なら、易しすぎる。B は「最初の連想を質問で否定されたあと、消去法で届く場所」に置く）。不思議は 1 つ（B を 2 か所隠さない）
   - **復元の納得感**: B を聞いた瞬間に A→C の**全ての語**が説明されるか（説明されない語が残るなら、B の選び方か物語の書き方が悪い）。B は物語の中で必然か（「なぜその人はそうしたか」に一言で答えられるか。かばん案の教訓 = もっと簡単な方法があるのになぜ、に答えられない案は落ちる）。B を聞いた読者が「そう考えればよかったのか」と自分を責められるか（知識ではなく想像力で届くか）
3. **コア宣言**（様式は固定。1 行）:

   ```
   コア: 物語「<物語の一文要約>」の <B = 隠す出来事・事情> を隠して「<A→C の見え方>」を出す → 復元: <B を戻した一文>
   ```

   この様式は `validate.py` が `puzzle_type = story` の行に対して検査する（2026-09-22 の再設計で置き換え。旧様式「〜と補わせる → 実際の B は〜」は NG になる）

4. **コア検査（story 固有。SKILL.md 工程 3 の共通検査と合わせて Yes でなければ戻る）**
   - 物語ゲートを通った物語から切り出しているか（切り出し中に物語を変えたら工程 2S に戻ってゲートをやり直す）
   - B は 1 か所・出来事や事情であって気持ちだけではない
   - 切り出し後の不可解さと復元の納得感（上の 2 軸）の両方に Yes が言える
   - 正解判定: 「B の一文」を言い当てられたら「正解です！」と宣言できる（部分的に当てた質問との境界を決めておく）
   - **共通検査の読み替え**: SKILL.md 工程 3 の「反転後の事実に落差があるか」は、story では「B を聞いて A→C の見え方が変わるか（同じ行動が別の意味に見えるか）」と読む。**役割の逆転や皮肉は必須ではない**

## 工程 4S: 切り出す（不思議にする）

- **既定は A→C を出して B を隠す**。C は「A の常識に反する行動・状態」を 1 つだけ強く書く（2 つ以上盛らない）
- **B の痕跡を問題文に 1 つ残す**: B があったことで A→C に残る「跡」（物の状態・時間のずれ・人の反応・環境の条件〔天候・時間帯〕）を 1 つ置く。B を直接指す語（B のカテゴリ名・道具名・関係を示す語）は置かない。この痕跡が工程 5 の取っ掛かりになる
- **説明の候補が複数残る書き方にする**: 「誰も入っていない」「関係のない人だ」と言い切ると、読者は考える前に「分からない」で止まる。状況証拠（「鍵はかかったまま」「初めて会う」）で止め、候補は質問で否定させる（否定はシートと想定質問へ）
- **否定で塞ぐ枝は真相と別カテゴリに限る**（U20 1 巡目の「最悪の日」案）: 「誕生日でも記念日でもない」と書いて真相が「妻と出会った日」だと、読者にはそれが記念日にしか見えず、否定文が不誠実に映って興ざめする。問題文で否定してよいのは、真相と明らかに別のカテゴリの枝だけ。真相と同じカテゴリの枝は否定せず、質問で「はい」と答えて先へ進ませる
- **C だけを出す（A も隠す）のは難易度 4 以上を狙うときだけ**。A まで隠すと動線が C 側 1 本になり取っ掛かりが消えやすい。まず A→C で作り、易しすぎるときに A を削る
- 問題文の草案を書き、「どういうこと？」「なぜ？」で締める → SKILL.md 工程 4.5 へ（登場人物の属性は A 型手がかり。物語で使った属性が真相のカテゴリを指すなら問題文からは外す）

## ゴール A の提示様式（人間ゲート = 物語ゲート + 切り出し）

1 問 = 2 ゴール（SKILL.md セクション 4）は維持し、**ゴール A では物語 2〜3 本と各の切り出し案を一度に提示**する。人間ゲートは 1 回。提示に含めるもの:

- 抽選した 3 語と選んだ語・捨てた語
- 物語 2〜3 本（各 5〜7 文）と、各本の物語ゲートの判定（要素・疑い）
- 各本の切り出し案: 隠す B・A→C の見え方（問題文の骨 1〜2 文）・コア宣言・不可解さと納得感の一行判定
- 推奨する 1 本とその理由
- Web 照合の先行が要る本（定番の筋・流通している構造の懸念）はゴール A の前に照合して結果を添える

ユーザーは「どの物語を採るか」「切り出しを変えるか」を判断する。**NG 理由は「物語が面白くない」と「切り出しが悪い」に分けて記録する**（前者ならその物語を捨てる。後者なら同じ物語で B を選び直す）。全部 NG なら再抽選（ゴール A をやり直す）。

## 工程 8: 物語の書き直し（工程 4.5〜7 で戻ってきたとき）

- 動線が 1 本しか引けない → B を A の状況の中で起きた出来事に置き直す（別の日・別の場所の出来事にしない）。それでも引けなければ隠す場所を変える（工程 3S）
- 現実性で落ちる → 物語の事情を「珍しい出来事」から「よくある事情の、見えていなかった一面」に置き直す（工程 2S に戻る）
- 照合で落ちる → B の筋が台帳 #01〜#15 や有名問題と同じなら、物語ごと捨ててモチーフからやり直す（言い換えでは逃げられない）
- 問題文の語と真相が合わない（工程 9 の突き合わせ）→ 物語を先に直し、問題文は物語から切り出し直す（問題文だけを直さない）

## 失敗パターン（story 固有）

**物語ゲートで落ちる型**

- **物語がない仕組みトリック**（21-4a-3 U20 の巡の 5 案 = かばんを抱えて体重計で差し引き / 痩せた猫を抱いて差し引き / 郵便受けに小鳥が営巣 / 自転車のダイナモで夜だけペダルが重い / 水筒の結露で教科書が濡れた）: 「仕組みが正しい」「実在する」は面白さの根拠にならない。人の事情も感情の動きもない案は、切り出しを工夫しても「へえ」で終わる。旧方式が探させていたのはこの型。**5 案とも 2026-09-22 に破棄**（再利用しない。no U20 の枠だけ新抽選で再作問する）
- **常識の再確認で終わる物語**（ダイナモ案）: 誰もが原因ごと知っている出来事は話したくならない
- **流通した比喩・定番の筋の物語**（U20 1 巡目の 3 案 = 「日記の天気」〔亡き夫の日記の天気欄が妻の機嫌 → 「機嫌 = 天気」は比喩として定着しており、天気の食い違いから機嫌へすぐ届く。切り出し NG・簡単〕/ 「先月の新聞」〔父が息子の絵日記の天気を図書館の新聞で調べる → 同じ仕組みの小話が多数流通し、ラテシン「異常気象」も絵日記の天気の後埋めを真相に使う。照合 NG〕/ 「最悪の日」〔日記に最悪と書いた日の失敗が妻との出会い → 読者は「出会いの記念日にケーキを買っているだけ」と読み、面白くない。物語 + 切り出し NG〕）: 物語は書けたが、3 本とも「どこかで聞いた筋」だった。物語ゲートの「流通した比喩・定番の筋ではないか」を先に問う
- **行動が豆知識に依存して唐突**（U22 の巡の「脱いだ靴下」= 迷子犬のために匂いの残る靴下を置く）: 主人公の行動が「一般には知られていない方法」を前提にすると、B を聞いても読者には行動の筋が通らず、物語として分からない。実話・推奨例があっても不可。行動は「事情さえ分かれば誰でもそうする」ものにする
- **身近でない出来事**（郵便受けの鳥の巣案）: 実例が Web にあっても、読者の生活感覚で「見ない・ありえない気がする」なら納得感が出ない。判定は「自分や身近な人が見聞きしたことがあるか」
- **題材を知らないと画が浮かばない**（U18 の巡のマラソン計測案）: 業界の運用・大会のルールに依存する話は一般の読者に像が結ばない。日用品・家庭・学校の範囲に置く

**切り出しで落ちる型**

- **気持ちだけの B**（U15 の巡の「防犯のため」「思い出のため」）: 動機は出来事まで掘る
- **不思議が C ではなく A にある**: 状況が奇妙なだけで結果に矛盾がない。読者は「変な人だな」で終わる
- **B が複数**: 「勘違いした」+「実は別人」+「実は昔の話」。隠すのは 1 か所。物語を短くする
- **最初の連想が真相**（U19 の巡の冷蔵庫案）: C を読んで一瞬で思いつく説明がそのまま B。難易度が立たない（U22 の巡の「足もとの点」= 端末の点が自分の足もと → 「自分が持っていた」が直行）
- **C の形が B のカテゴリを指す**（U22 の巡の「休んだ日の記録」= 物語はユーザー評価「いい感じ」）: 「ある人がいないと結果が悪くなる」形の C は、読んだ瞬間に「その人に隠れた役割があった」へ届く。残るのは役割の中身当てだけで、B を隠しても難易度が立たない。不在・交代・欠席で結果が変わる C は避けるか、変化の原因が人以外に見える切り出しにする
- **言い切りで候補を塞ぐ**: 「誰も入っていない」「火は使っていない」と書くと読者は考える前に止まる。状況証拠で止める
- **登場人物の属性で B のカテゴリが漏れる**（SKILL.md 4.5）: 「少年」「老人」「新人」で遊び・昔話・失敗が絞れる。登場人物は「男・女」を既定にする
- **必然性のない回りくどい行為**（かばん案）: 「もっと簡単な方法があるのになぜ」に一言で答えられない B は、物語としても嘘になる

**照合で落ちる型**

- **流通している構造**（猫案 = らてらて「デブエット成功」と同構造）: 独立に到達しても工程 7 で落ちる。差し引き・すり替えのような算数的トリック、定番の筋（遠回りが目的達成・見えない合図・本人が別人・実は昔の話）に乗る案は、ゴール A の前に Web 照合を先行する
- **有名問題の構造**: story 型は台帳の classic の大半（エレベーター・雪だるま・水を頼む客・虎へ走る女性…）。工程 7 を意味誤誘導型より厳しくかける
