# 物語復元型（story）の工程 3・4

SKILL.md の工程 3・4 の位置に差し込んで使う分冊。物語復元型は「完結した物語 A→B→C から B を抜いて A→C を出す」型で、語の仕掛けは使わない。**その代わりに、読者が A→C から B を誤って補完すること**をコアにする。誤った補完が立たない案は「不思議なだけの穴埋めクイズ」で、コアがない。

通過した story 型は 2026-09-22 時点で 3 問（21-4a-3 U17「誰も入っていないのに焦げた畳」= 留守中に窓辺の水入りガラス鉢が日光を集めて畳を焦がした / U18「濡れた手紙を乾かしたら白紙になった」= 濡れた手紙をドライヤーで乾かしたら消せるボールペンのインクが熱で透明になった / U19「雨が降ると鳴るチャイム」= 庭の犬が家に入れてもらうために鼻でチャイムのボタンを押すことを覚えた）。それ以前の 2 案（U15 の巡）はコア宣言で NG で、2 案とも B が「留守宅の防犯のため」「故郷の砂を集めるため」という動機の説明だった。本分冊は記事の原理 + NG 案 + 通過問の知見で組んでいる。**通過 3 問から取った形**: ① U17 = B は「人がいない間にその場所で仕組みだけが動いた物理現象」。人がいないことで読者は「人の仕業」を補い、仕組みへの着地で落差が出る。② U18 = **因果の反転**。読者が原因だと信じる出来事（濡れた）は原因ではなく、本人の当たり前の手当て（乾かした）が仕組みを動かした。どちらも B は「誰でも画が浮かぶ日用品の、見えていなかった性質」。③ U19 = **押した者の反転**。読者は「押した者はいない（機械の誤作動）」と補うが、実際は人ではない者（犬）が目的を持って押していた。B は現象ではなく登場者の行為で、答えを聞くと場面の絵（雨の玄関で鼻を押しつける犬）が丸ごと入れ替わる。**U18 の巡で NG になった 2 案**（マラソン = 同じ号砲なのに記録が逆転〔スタートラインを越えてから計測〕/ 自転車 = 同じ型の自転車に鍵が合って乗って帰った）から取った条件: 題材を知らない読者に画が浮かばない仕組みは正しくても通らない / 反転が「別物だった」で終わる案はひねり不足（読者の信じた前提そのものを壊す反転にする）。**U19 の巡で NG になった 4 案**（霜柱が苗を持ち上げた / 植木鉢の土が凍って中から割れた / 留守宅が冷蔵庫より冷えた / 隣家のワイヤレスチャイムの混線）から取った条件: A の行為が B の起きる季節・条件で現実に行われるか / 現象の説明だけの B は正しくても驚きがない / C の最初の連想が真相に直行する案はコアがない / 技術的な原因だけの答えは絵が反転せずひねり不足。以後の通過で知見が増えたら書き換える。

## 工程 3S: 物語を書く → コア宣言

1. **A→B→C を 3 文で書く**
   - A = 状況（誰が・どこで・何をしている。因果の受け皿はここに置く）
   - B = **隠す出来事・仕組み**（「何が起きたか」「どうなっているか」を一文で言える事実。「〜のため」「〜したかった」という動機・感情は B にしない。動機は真相の周辺事実として書くのは可）
   - C = 結果として見える行動・状態（A の常識に反して見える。ここが「不思議」の置き場）
2. **誤った補完を 1 つ書く**: A→C だけを読んだ人が B に何を入れるか。「読者は B を〈X〉と補う」と一文で書く。これが工程 3 の〈誤認させる読み〉に当たる
   - 補完が定まらない（何が起きたか全く見当がつかない）→ A か C が抽象的すぎる。具体化して戻る
   - 補完が複数あって割れる → 不思議を盛りすぎ。C を 1 つに絞る
3. **コア宣言**（様式は固定）:

   ```
   コア: 「<A→C の要約>」から読者に B を <誤った補完> と補わせる → 実際の B は <出来事・仕組み>
   ```

   この様式は `validate.py` が `puzzle_type = story` の行に対して検査する（2026-09-20 U17 で型別検査に拡張。misdirection の様式で書くと NG になる）

4. **コア検査（story 固有。SKILL.md 工程 3 の共通検査と合わせてすべて Yes でなければ戻る）**
   - **B は出来事・仕組みか**: B を一文で言ったとき「何が起きた / どうなっている」が言えているか。「〜のためにそうしていた」で終わるなら動機であって B ではない（U15 の巡の 2 案）。動機しか思いつかない案は、その動機を実現する**具体的な出来事**（誰が何をした・何が変わった）まで掘り、それを B にする
   - **誤った補完が強制されるか**: A→C を読んだ人の大半が同じ X を補うか。語の仕掛けがない分、「常識的な物語の補完」が誤読を担う。X が弱い（読者が「分からない」で止まる）案は捨てる
   - **B は A と C の両方につながっているか**: B が A の状況の中で起き、C を直接引き起こす。B が A と無関係（別の場所・別の日の話）だと動線が 1 本になる
   - **落差**: B を一文で声に出して「そういうことか」が出るか。X と B の距離（誤った補完がどれだけ違うか）が落差の大きさ。**読者が既にその因果を知っていないか**も見る（U20 の巡のダイナモ案「ライトを点けるとペダルが重くなる」: 誰もが実感として原因ごと知っている仕組みを B にすると、答えが常識の再確認になり「ああ、まあそうだよね」で終わる）。**身近であるべきは題材（物・場面）、意外であるべきは役割・因果**。両方が既知の案も、両方が未知（身近でない）の案も落ちる
   - **役割の逆転か行為の皮肉があるか**（U19 の巡の植木鉢案）: B が「水は凍ると膨らむ」「霜柱は土を持ち上げる」のような現象の説明だけなら、正しくても「ただの科学的事象」で驚きがない。通過した B は、物が常識と別の役割を果たす（金魚鉢がレンズ・チャイムが犬の合図）か、本人の行為が裏目に出る（乾かしたから消えた）のどちらかを持つ。どちらもない案は捨てる
   - **最初の連想が真相に直行しないか**（U19 の巡の冷蔵庫案「留守宅の中が冷蔵庫より冷えた」）: C を読んだ人が最初に思いつく説明（「ものすごく寒い場所」）がそのまま真相なら、X が立たずコアがない。X は「最初の連想」で、真相は「その連想を否定されたあとに消去法で届く場所」に置く
   - **答えで絵が反転するか**（U19 の巡の混線案）: 真相が「電波の混線」「センサーの誤作動」のような技術的原因だけだと、状況は説明できても読者の頭の中の場面が変わらない（ひねり不足）。技術的原因は誤読 X の側に回し（U19 は「雨で誤作動」を X にした）、真相には登場者の行為・物の別の役割を置く
   - **季節・条件の整合**（U19 の巡の霜柱案「夕方に植えた苗が翌朝高くなっていた」）: B が起きる条件（真冬の冷え込み等）のもとで、A の行為（苗を植える）を人はふつうするか。仕組みが正しくても、A と B が同じ季節・状況に同居しない案は現実離れとして落ちる。SKILL.md 工程 6 の動機の現実性と合わせて 1 回問う
   - **B の行為に必然性があるか**（U20 の巡のかばん案「かばんを抱えて体重計に乗り差し引きで量った」）: B が回りくどい手順のとき、「もっと簡単な方法（かばんだけを乗せる）でなぜ済まさないか」に一言で答えられるか。答えられない案は仕組みが正しくても人間ゲートで落ちる（じっと乗らない生き物なら「抱いて量るしかない」と答えられる）
   - **自分の Yes を疑う**（U17 で機能した運用）: 各項目に「疑い: 〜」を一行添えて、Yes が崩れる条件を書く（例: 「誰も入っていない」と言い切ると X が立たなくなる → 問題文の書き方の課題として工程 4S へ持ち越す）。提示時は懸念（語感・仕組みがトリビアとして流通している 等）を先出しし、人間ゲートの判断材料にする

## 工程 4S: 切り出す（不思議にする）

- **既定は A→C を出して B を隠す**。C は「A の常識に反する行動・状態」を 1 つだけ強く書く（意味誤誘導型の「逆を 1 つ足す」に当たる。2 つ以上盛らない）
- **B の痕跡を問題文に 1 つ残す**: B があったことで A→C に残る「跡」（物の状態・時間のずれ・人の反応・**環境の条件**〔天候・時間帯。U17 の「よく晴れた日」〕）を 1 つ置く。B を直接指す語（B のカテゴリ名・道具名）は置かない。この痕跡が工程 5 の取っ掛かりになる
- **誤った補完 X の枝を言い切りで塞がない**（U17）: 「誰も入っていない」「火は使っていない」と言い切ると、読者は X を補う前に「分からない」で止まる。状況証拠（「鍵はかかったまま」「火の気のない」）で止めて、X を質問で否定させる（否定はシートと想定質問へ）
- **C だけを出す（A も隠す）のは難易度 4 以上を狙うときだけ**。A まで隠すと動線が C 側 1 本になり、既定難易度 4（A 型手がかり 0 個）でも取っ掛かりが消えやすい。まず A→C で作り、易しすぎるときに A を削る
- 誤った補完 X を問題文が壊していないか見る（X を否定する語が問題文にあると、読者は B を探す前に「分からない」で止まる）
- 問題文の草案を書き、「どういうこと？」で締める → SKILL.md 工程 4.5 へ

## 工程 8: A→B→C の書き直し（工程 4.5〜7 で戻ってきたとき）

- 動線が 1 本しか引けない → B を A の中で起きる出来事に置き直す（別の日・別の場所の出来事にしない）
- 現実性で落ちる → B を「珍しい出来事」ではなく「よくある仕組みの、見えていなかった一面」に置き直す（通過例の着地: 救急車の前面表記・配信の遅延・氷鬼のルール・水入り鉢の収れん〔story U17〕）
- 照合で落ちる → B の構造が台帳 #01〜#15 と同じなら、モチーフからやり直す（B の言い換えでは逃げられない）

## 失敗パターン（story 固有）

- **動機で説明する B**（U15 の巡の 2 案）: 「防犯のため」「思い出のため」「習慣だから」。動機は B ではない。何が起きたかまで掘る
- **不思議が C ではなく A にある**: 状況が奇妙なだけで、結果に矛盾がない。読者は「変な人だな」で終わり、B を補完しない
- **誤った補完が立たない**: A→C が抽象的で、読者が何も補えない。穴埋めクイズになる
- **B が複数**: 「勘違いした」+「実は別人」+「実は昔の話」。B は 1 つ。物語を短くする
- **登場人物の属性で B のカテゴリが漏れる**（SKILL.md 4.5 の A 型手がかり）: 「少年」「老人」「新人」で遊び・昔話・失敗が絞れる。登場人物は「男・女」を既定にする
- **題材を知らないと画が浮かばない B**（U18 の巡のマラソン案）: 大会の計測方法・業界の運用のように、体験した人にしか像が結ばない仕組みは、正しくても子ども・一般の読者に落差が出ない。B は日用品・家庭・学校の範囲に置く
- **実在はしても身近でない出来事の B**（U20 の巡の郵便受けの鳥の巣案）: 実例が Web に複数あり Web 照合もクリアした出来事でも、読者の生活感覚で「あまり見ない・ありえない気がする」と感じられれば納得感が出ずに落ちる。**実在の証拠は納得感の裏付けにならない**。判定は「自分や身近な人が実際に見たことがあるか・聞いてすぐ画が浮かぶか」で行い、珍しい実話より平凡な仕組みの見えていなかった一面を選ぶ
- **反転が「別物だった」で終わる B**（U18 の巡の自転車案）: 「実は他人の物・別の場所」は出来事として成立しても、読者の信じた前提を壊さないのでひねり不足。前提（原因・順序・場所）そのものが違うと分かる反転にする
- **現象の説明だけの B**（U19 の巡の霜柱案・植木鉢案）: 「凍って膨らんだ」「霜柱が持ち上げた」で終わる B は、役割の逆転も皮肉もなく「ただの科学的事象」と判定される
- **最初の連想が真相**（U19 の巡の冷蔵庫案）: 「冷蔵庫の外の水が凍った」→ 一瞬で「北極のように寒い場所」に直行し、X が立たない
- **技術的原因だけの答え**（U19 の巡の混線案）: 「隣家のチャイムと混線」は事象として面白くても、答えで場面の絵が変わらない。技術的原因は X に回す
- **A と B の季節・条件が同居しない**（U19 の巡の霜柱案）: 霜柱が立つ季節に苗は植えない。仕組みの正しさより先に「その条件で人は A をするか」を問う
- **必然性のない回りくどい行為の B**（U20 の巡のかばん案）: 差し引きで量る等の手順を B に置くとき、単純な方法で済む対象だと「そもそもそうしない」で落ちる。回りくどさがその対象にとって唯一の方法になっているか（コア検査の必然性の項）を先に問う
- **流通している構造のコア**（U20 の巡の猫案「痩せた飼い猫を抱いて差し引きで量り、増えた数字にほっとした」）: 「抱いて乗って差し引き × 増えた数字を喜ぶ」は、らてらてに作者自身が「ほぼ再出題」と言う投稿問題（デブエット成功）がある流通構造で、独立に到達しても工程 7 で落ちる（素材化まで済ませた後の Web 照合で判明し差し戻しになった）。差し引き・すり替えのような算数的トリックを B に置く案は、コアゲートの段階で Web 照合を先行する
- **有名問題の構造**: story 型は台帳の classic の大半（エレベーター・雪だるま・水を頼む客・虎へ走る女性…）。工程 7 を意味誤誘導型より厳しくかける
