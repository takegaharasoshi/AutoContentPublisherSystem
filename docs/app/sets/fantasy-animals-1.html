1. テーマ

現実に存在していそうで実在しない、架空のかわいい動物を紹介する画像を生成する。野生の姿を偶然写真に収めたかのような自然な写真風の構図とし、画像内に架空の動物の名前とその特徴（外見・生態など）の説明文を記載する。

3. スケジュール（投稿頻度）

1 日 3 回（7:00 / 12:00 / 21:00 JST）。Phase 13-1（2026-07-22、ユーザー決定）で確定し、既存プレースホルダ Scheduler（acps-prod-image-generation-schedule）を転用して cron 式 cron(0 7,12,21 * * ? *)（Asia/Tokyo）+ ENABLED で本番化した（operation.html セクション 2.1 手順 3 の decision、現行値は infra/workflow.html セクション 1.5）。画像生成に数分かかるため、実投稿はスケジュール時刻の数分後になる。

4. プロンプトの作り方

固定文言方式。prompt_configs.prompt_text への直接 INSERT で管理する（初期運用は 1 セット 1 prompt_config。1 枚だけ生成されるよう文言で制御する。batch-flow.html の decision）。14-11 時点の登録文言は以下（ユーザー決定）。

実在しそうで実在しない架空の小動物を紹介する、図鑑風の縦長画像を1枚だけ作ってください。

【全体のスタイル】
・自然の生息地で偶然撮影されたかのような、実写風の高精細なネイチャー写真をベースにする。
・自然光でやわらかく、背景は浅い被写界深度でぼかす。落ち着いた自然の色調にする。
・その写真の上に、白い細身の明朝体による図鑑風の文字レイヤーを重ねる。
・細い罫線や小さな葉のモチーフなど、繊細で上品な装飾を少しだけ添える。

【被写体】
・実在しそうでどこにもいない、かわいい小動物を1匹だけ。
・生息環境は毎回変えること。森・渓流・高原・草原・雪原・洞窟・湿原・海辺・岩場・竹林などから選び、その環境に合った姿・毛色にする。
・毛並みや質感がリアルで、自然なポーズ。カメラ目線でなくてもよい。
・動物はこの画像の主役です。画像の高さの半分以上を占める大きさで、はっきりと大きく写すこと。

【記載する文字要素】（この構成と分量を守る）
1. リード文：2行。1行あたり15〜20文字程度。その動物との出会いを伝える文にする。文章は毎回必ず変えること。（例「森の水辺で偶然出会った、／とても珍しい生きもの」「雪の残る岩場で見かけた、／小さな幻の住人」）
2. 名前：カタカナ4〜7文字。画像の中で最も大きく、字間を広めにとる。名前は毎回変え、同じ書き出しを繰り返さないこと。
3. 名前のローマ字表記：名前のすぐ下に小さく。先頭の1文字だけ大文字、残りは小文字にする（例「Mizuhotaru」）。
4. 基本情報：「分類」「生息地」「体長」「食性」の4項目。ラベルは小さな角丸タグ、値は10〜20文字程度。分類は「ネズミ目リス科」のように実在する目・科を基にした表記にし、その動物の名前をそのまま科名・属名に使わないこと。
5. 特徴：3項目。1項目あたり30〜45文字程度で、1〜2行に収める。行頭に小さな葉のアイコンを置く。

【レイアウトの条件】
・縦長（2:3）の構図。
・動物と文字が重ならないように、画像を大きく2つの領域に分けて配置する。動物を大きく写したうえで、背景のぼけた部分に文字をまとめる。
・文字は必ず全文が画像の枠内に収まるようにし、途中で途切れさせない。
・スマートフォンのリール動画として表示するため、画像の右端12%と下端15%には文字を置かず、背景のみにする。
・文字はスマートフォンでも読める十分な大きさにする。

【禁止事項】
・枠線・額縁・複数コマ・コラージュにしない。
・意味の通らない文字や誤字を出さない。日本語は自然な表記にする。
・生成する画像は1枚のみ。

生成パラメータ（parameters カラム）は 11-2（画像生成 API の疎通確認）の実プロンプト検証で確定し、14-10 の動画方式への切替で size を 2:3 の縦長へ変更した（キー仕様は 方式設計書 セクション 3）。

{"model": "gpt-image-2", "size": "1024x1536", "quality": "high", "n": 1}
decision: 14-11 でプロンプトを全面改訂（2026-07-26） 11-1 の登録文言は 1:1 時代のもので、構成・文字量・トーンの指定が無く品質が安定しなかった。加えて 14-10 のリール実投稿で画像内の文字が左右で見切れていたため、以下を明示した文言へ差し替えた。①構成の固定（リード文 2 行 / 名前カタカナ 4〜7 字 / ローマ字 / 基本情報 4 項目 / 特徴 3 項目）②写真トーン（実写風ネイチャー・浅い被写界深度・自然光・白い細身の明朝体）③Instagram UI セーフエリア（右端 12%・下端 15% には文字を置かない）④毎回変える要素（生息環境・名前・リード文）。
セーフエリアの数値は、合成後の前景がフレームの x∈[44,1036] / y∈[216,1704] を占めることから換算した実効値（上下の帯が Instagram の上部バーをほぼ吸収するため、上側の制約は不要）。合成方式は development-log.md の 14-11 を参照。実 API での試し打ちを 3 巡（6 枚）行って確定している。
