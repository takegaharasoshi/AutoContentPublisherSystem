3. テスト内容とやったこと

3.1 テストデータ（188 件）

  • 問題ごとのケース: 5 問（U01・U13・U18・U20・U26）× 21 件 = 105 件。内訳は 1 問あたり ① 10 件・② 2 件・③ 3 件・④ 2 件（うち 1 件は「〜ってこと？」の質問の形）・⑤ 2 件・⑥ 2 件。① には正解の判定（はい / いいえ / 関係ありません）も付けた
  • 共通のケース: ⑦〜㉒ の 16 種 × 5 件 + 3 件 = 83 件。どの問題に付いても成り立つ文面で、5 問に順番に割り当てた。試行 3 で「作品へのけなしは ⑮」と決めたため、元の ⑲ のうち 3 件（「つまらん、センスない」「バカみたいな問題だな」「そういう人たちを見下す感じ、無理」）を ⑮ に付け替え、⑲ には人への攻撃・性的な文を 3 件足した（⑮ 8 件・⑲ 5 件）
  • 作り方: プロンプトの調整に使った想定質問（expected_questions）は使わず、Codex に新しく書かせ、Claude が正解ラベルを検めた。置き場は judge-trial/data/
  • 弱点: ① の質問は書き手が確定事実シートの言い回しに寄せてしまい、実際のコメントより易しめ。5 問だけの小さな試走なので、数値の幅は大きい。投稿の絵（イラスト）についての質問はまだテストデータにない

3.2 測ったこと

  • 種別の一致率（全体・区分別・種別ごと）、① の判定の一致率
  • P1〜P7（上の基準をそのまま機械で数える。P1 は既存の leak_count.py の核心語辞書で漏れ候補を拾う）
  • パターン 1 の応答時間・出力トークン（うち推論）・打ち切り件数、パターン 2 の応答時間・入力トークン
  • 採点の約束（試行 3 から。過去の試行も同じ約束で数え直した）: 「〜って関係ある？」「〜は重要？」への「いいえ」は、正解ラベルが「関係ありません」でも一致とする（質問への答えとして意味が正しいため。21-4a の probe_test.py と同じ扱い）

3.3 試行の記録

  • 試行 1（2026-09-27）: 2 方式を 185 件で実行。パターン 1 = 96.2%、パターン 2 = 57.3%。パターン 2 は段 A の指示文に「質問の形の推理も推理に入れる」と書いていたため、① のはい / いいえ質問 50 件中 38 件が推理に流れた
  • 試行 2（同日）: パターン 2 の段 A の指示文を「言い切った推理だけを推理に入れる」に直して再実行（設計どおりに戻しただけ。閾値は変えていない）。パターン 2 = 73.5%。パターン 1 は試行 1 のまま
  • 追加の測定: パターン 1 で打ち切られた 1 件を、出力上限 400 と 800 で 3 回ずつ実行。400 は推論 252〜400 トークンで 3 回中 1 回打ち切り、800 は 173〜264 トークンで 3 回とも収まった → 上限 800 に決定（ユーザー承認）。API は gpt-6-luna の effort に max を受け付けないため xhigh を使う（ユーザー承認）
  • 試行 3（同日・ユーザー指示の改善）: パターン 1 はプロンプトに 4 点を追加（開示文 70 字以内・作品へのけなしは ⑮・主語が曖昧な質問は ③・絵についての質問の扱い）し、上限 800 で実行。パターン 2 は段 A を「A1 大分類 6 択（問題文なし）→ A2 大分類ごとの細分類」の 2 段に変えた。テストデータは ⑮ / ⑲ の付け替えで 188 件。結果: パターン 1 = 97.9%（184/188）、パターン 2 = 87.8%（165/188）

5. パターン 1（gpt-6-luna の一括方式）

5.1 処理方式

  • 呼び出し: コメント 1 件につき chat completions を 1 回。response_format を JSON スキーマ（strict）にし、{種別, 判定, 返信文} を返させる（種別を明示させることで、コードの上書きと種別一致率の集計ができる）
  • プロンプト: 5.1 のマスタープロンプトを改訂した judge-trial/prompts/pattern1_rules.txt。手順 1 で 22 種を定義して種別を選ばせ、手順 2 で判定、手順 3 で種別ごとの返し方（80 字以内・探偵口調・① は判定語 + 真相に触れない 20 字以内の一言）を書く。「荒らしには返信しない」はやめ、⑱〜㉑ は返信文を空にしてコードに任せる
  • 試行 3 で足したルール（ユーザー指示）: ① 正解時の開示は 70 字以内（全体 80 字以内）② 「つまらない」「センスない」など作品そのものへのけなしは ⑮、⑲ は人への攻撃・差別・性的な内容に限る ③ 「それ」「あれ」「彼」「あの人」が問題文の誰・何を指すか一つに決まらない質問は ③ ④ 投稿の絵についての質問は、絵を場面のイメージとして扱い、絵にだけ描かれた細部は根拠にしない
  • パラメータ: effort xhigh・出力上限 800・温度は送らない

5.2 結果（試行 3）

  • 種別一致率 97.9%（184/188）（試行 2 は 96.2%）。① 50/50・② 10/10・⑤ 10/10・⑥ 10/10・⑦〜㉑ はすべて満点
  • 効いた改善: ⑲ と ⑮ の境目を決め（テストデータのラベルも付け替えた）、⑲ 5/5・⑮ 8/8・P6 の定型率 100%。開示文 70 字の指示で P7 違反 0 件（正解時の返信は 55〜72 字）。上限 800 で打ち切り 0 件（最大 667 トークン）
  • 残った誤り 4 件: ③ → ① が 2 件（「その子は彼に会ったことがある？」「それはまだ覚えてるの？」。曖昧な主語のルールで 3 件 → 2 件に減ったが残る）、④ → ⑤ が 1 件（要点を言い換えた質問形の正解推理）、㉒ → ⑧ が 1 件（「答案是什么？」を日本語として読み、ネタバレ要求と判定。返信は日本語で「答えは秘密」と返しており実害は小さい）

誤り・違反の例:

  • 「その子は彼に会ったことがある？」 — 正解 ③ 答えられない質問 → 判定 ① はい / いいえ質問（いいえ）。返信「いいえ。鋭い視点ですね、捜査を続けましょう。」
  • 「それはまだ覚えてるの？」 — 正解 ③ 答えられない質問 → 判定 ① はい / いいえ質問（はい）。返信「はい。記憶の糸は切れていませんね。」
  • 「息子が嫁と義母の言葉を仲直りのために作り替えて訳していた。日本語を覚えた嫁に本音が伝わり、けんかが始まった、ってこと？」 — 正解 ④ 正解推理 → 判定 ⑤ 惜しい推理。返信「惜しい！」
  • 「答案是什么？」 — 正解 ㉒ 外国語 → 判定 ⑧ ネタバレ要求。返信「誰かが正解するまで、答えは秘密です。質問で少しずつ絞ってみてください。」

5.3 見えた課題と次の打ち手

  • 曖昧な主語の質問 → 「その子」「彼」が問題文の登場人物に当てはまりうる場合の判断を例つきで足す。ただし ③ として聞き直させるか ① として答えるかは体験に関わるので、厳しくしすぎない（ユーザー判断）
  • 漢字だけの中国語 → 「かなを 1 字も含まないコメントは foreign を疑う」とプロンプトに足すか、パターン 2 と同じ段 0 の文字種規則をコードで前に置く
  • ⑤⑥ の言い回しの偏りは、種別判定ができているので問題にしない（ユーザー判断 2026-09-27）

6. パターン 2（Jev の段階判定 + 定型文）

6.1 処理方式

  • Jev の呼び方: POST https://api.typesafe.ai/v1/systemone（model: jev-latest）。choice は選択肢ごとの確率、noul は命題が真である確率を返す。指示文は英語、コメントと問題は日本語のまま渡す
  • 段 A1 大分類（試行 3 で新設・ユーザー指示）: 問題文は渡さず、「水平思考クイズを Instagram に出したら、こんなコメントが来た」という説明とコメントだけで、質問 / 推理 / 依頼 / 反応 / 不適切 / その他 の 6 択にする。各選択肢には含まれる種別と具体例を添える（例は評価データの文面を使わずに書いた）。作品へのけなしは「反応」、人への攻撃は「不適切」と説明に書いた
  • 段 A2 細分類: 大分類ごとに、質問 → ①②③、依頼 → ⑦⑧⑨、反応 → ⑩〜⑯、不適切 → ⑱〜㉑ から選ぶ（これも問題文なし）。推理は A2 を飛ばして段 B へ、その他は ㉒
  • 正解判定に使う要点: 問題ごとに真相の要点 2〜3 個（truth_points）と開示文（reveal_text・70 字以内）を用意した（試走では 5 問分の仮の値）。ストックへの追加は 21-6c
  • 定型文: 種別ごとに 3 通り以上を持ち、comment_id のハッシュで選ぶ（状態を持たずに言い回しを散らす）

6.2 結果（試行 3）

  • 種別一致率 87.8%（165/188）（試行 2 は 73.5%）。質問系 72% → 93%、その他 81% → 94% に上がった
  • 効いた改善: ① → ⑥ の誤り（質問を推理と判定）が 13 件 → 1 件。A1 で「質問」か「推理」かを問題文なしで見分けるほうが、19 択から選ぶより迷いが少ない。⑨ 2/5 → 5/5、⑲ 5/5（付け替え後のラベル）、㉒ の韓国語・中国語（感想）も A1 の「その他」で拾えた
  • 残る最大の弱点は推理系（56.7%）: ⑤ 惜しい推理 0/10（9 件が ⑥、1 件が ①）。要点の 1 文に複数の事柄が入っているため、一部だけ言い当てた推理の確率が 0.1〜0.3 に留まり、閾値 0.5 に届かない。④ も 3 件が ⑤⑥ に落ちた（言い換えた推理・質問形の推理で要点ごとの確率が下がる）
  • そのほか: ③ → ① が 4 件（曖昧な主語。A2 は問題文を見ないので主語が決まるか判断できず、段 C の閾値 0.2 も超える）、⑱ → ㉒ / ⑩ が 2 件（「QWERTYZZZ」は段 0 の英字規則で外国語に、「あああ???ぴょ」は反応に）
