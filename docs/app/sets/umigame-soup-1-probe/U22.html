合否と評価はサマリーページにある。共通ケースは問題に順番に割り振っている。

「判定内容」は 種別 / 答え / どの判定を採用したか の順。答えは はい / いいえ / 関係ない の 3 値で、真相と確定事実のどちらからも決められないとき（Jev は確信度が足りないとき）は「関係ない」になる。
