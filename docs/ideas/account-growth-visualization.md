## 要旨

運用者のモチベーションが下がっている（在庫補充の速度・計画書の進捗の鈍化に表れている）。原因の仮説は、収益化までの道のりが遠く、すぐに成果を感じられないこと。
そこで各アカウント（セット）の成長を見える化し、前進を実感できるようにする。

現時点の方向（2026-11-11 の壁打ち。未決を含む）:

- **届くレポート（週 1・数行）+ 見たいときだけ開くダッシュボード（アーティファクト）**の 2 段。AWS 側に新しい仕組みは作らない
- 投稿単位・日単位では見せない（当たり外れが大きく、毎日「伸びなかった」になる）。**開始からの長い推移**と節目までの残りで「ミクロは凸凹・マクロは成長」を表す
- 嬉しい数字はフォロワーと再生数。ただしフォロワーだけを見ていると pref-ranking-1 の立ち上がりのような変化を見落とす（下の実データ）
- 素材は既存の集計ランナー `content/insights-analysis/run_queries.py`（`kpi_account_monthly`・`kpi_post_monthly`・`weekly_age_fixed`・`account_daily`）で足りる見込み

## 原文メモ

最近このプロジェクトのモチベーションが結構下がってきています。それは各アカウントの在庫の補充速度や、計画書の進捗具合から見ても明らかだと思います。

その原因として考えているのは、収益化までの道のりが長すぎてかなり遠い目標になってしまっており、すぐに成果を感じられる状況ではないということです。

ただ一方で、今やっていることやアカウント自体は成長している認識もあります。例えばフォロワーが少しずつ増えていたり、閲覧数やいいね、コメントが増えていたりと、成長自体はしている気がします。

なので、そういった成長を可視化（見える化）することによって、モチベーションが回復するのではないかと考えています。

そのため、新しいアイデアとしては「各アカウントの成長の可視化」をテーマに対策をしていきたいと考えています。

## 壁打ち記録

### 2026-11-11（1 回目・継続中）

**論点と判断**

- 仕組みを作る前に実データを 1 回見る、を先に行った。体感の「成長している」は半分当たりで、セットごとに様子が違った
- 「見に行くダッシュボード」より「届くレポート」が先（落ちているときは開かない）。ユーザーも同意し、レポート → 詳細はダッシュボードの 2 段に
- 本格的なダッシュボードを AWS で作る気はない（ユーザー）。Claude Code のスケジュール実行で整形 → アーティファクト更新 → 通知、のイメージ
- その日の投稿の成績は見せない（ユーザー）。伸びない投稿が多くモチベーションにつながらないため
