運用者のモチベーションが下がっている（在庫補充の速度・計画書の進捗の鈍化に表れている）。原因の仮説は、収益化までの道のりが遠く、すぐに成果を感じられないこと。
そこで各アカウント（セット）の成長を見える化し、前進を実感できるようにする。

## 原文メモ

最近このプロジェクトのモチベーションが結構下がってきています。それは各アカウントの在庫の補充速度や、計画書の進捗具合から見ても明らかだと思います。

その原因として考えているのは、収益化までの道のりが長すぎてかなり遠い目標になってしまっており、すぐに成果を感じられる状況ではないということです。

ただ一方で、今やっていることやアカウント自体は成長している認識もあります。例えばフォロワーが少しずつ増えていたり、閲覧数やいいね、コメントが増えていたりと、成長自体はしている気がします。

なので、そういった成長を可視化（見える化）することによって、モチベーションが回復するのではないかと考えています。

そのため、新しいアイデアとしては「各アカウントの成長の可視化」をテーマに対策をしていきたいと考えています。

**LINE 通知の下調べ（公式ページ・2026-11-12 時点）**

- 無料のコミュニケーションプランは月額 0 円・月 200 通まで。超えると送れない（追加購入不可。API は 429 を返す）。数え方は「送った相手の人数」で、1 回の送信に複数の吹き出しを入れても 1 通。週 1 回・自分 1 人あてなら月 4〜5 通で、枠の心配はない（https://www.lycbiz.com/jp/service/line-official-account/plan/ ・ https://developers.line.biz/en/docs/messaging-api/pricing/）
- 数えられるのはプッシュ・マルチキャスト・ブロードキャスト・ナローキャスト。応答メッセージは数えない（同上）
- 送り先の自分の userId は、LINE Developers コンソールのチャネル「Basic settings」の「Your user ID」で見られる（Webhook を作らなくてよい。ビジネス ID が LINE アカウントに紐づいている場合に表示）（https://developers.line.biz/en/docs/messaging-api/getting-user-ids/）
- 送信は `POST https://api.line.me/v2/bot/message/push` に `Authorization: Bearer <チャネルアクセストークン>` と `{"to": "<userId>", "messages": [{"type": "text", "text": "..."}]}`（https://developers.line.biz/en/reference/messaging-api/）
- トークンは 4 種類。長期（無期限・チャネルに 1 本・コンソールの「Messaging API」タブで発行）がいちばん手軽。期限つき（v2.1 = 最長 30 日、短期 = 30 日、ステートレス = 15 分）は発行の手間が増える（https://developers.line.biz/en/docs/basics/channel-access-token/）
- トークンの置き場の案: リポジトリの外（`~/.bashrc` の環境変数。`ANTHROPIC_API_KEY` と同じ扱い）。AWS の Secrets Manager には置かない（AWS 側に仕組みを作らない方針のため）
- 未確認: 公式アカウントを友だち追加していない相手へのプッシュの扱い（自分で友だち追加すれば済む）、今月の送信数を調べる API のパス、1 回の送信に入れられる吹き出しの上限
