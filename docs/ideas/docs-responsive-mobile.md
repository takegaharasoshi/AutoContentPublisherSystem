## 壁打ち記録

### 2026-09-20 — 表の縦長化対策と計画書改善の分離

- 論点: スマホで最も困るのは、各所の表が狭い列に折り返されて極端に縦長になること。計画体系・事業戦略の表が具体例。
- 判断: 一般の表は列幅確保 + 表内横スクロール、課題・アイデア一覧はスマホでカード表示とする方向に合意。
- スコープ変更: 当初提案した計画のステップ表示の再構成は、PC でも見づらいという問題と合わせて別課題 I-036 に分離。ユーザーの明示指示により今回のスマホ対応から除外。計画書内を含む一般の表の共通対策は残す。
- 積み残し: 表示幅・代表ページ・カードの項目順・受け入れ基準、採用判断と開発レーン向け転記下書き。
- 着地: 醸成中。課題側は起票のみ行い、この場では壁打ちしない。


### 2026-09-20 — カード内の補足情報の折りたたみ

- 判断: 一覧で判断する情報は常時表示し、対象パス・発生履歴・更新日などはカード内で展開する案にユーザーが同意。
- 初期スコープ: 既存項目・既存文面を使い、短い課題名の独立管理や新規要約の作成は要求しない。
- 次の検討用たたき台（未合意）: 幅 360 / 390 / 430 CSS px と PC 幅 1280 CSS px で、計画体系・事業戦略・課題一覧・アイデア一覧を代表ページとして確認する。ページ全体は横にはみ出さず、一般の表だけ横スクロールし、カードの主要項目は展開せず読めることを確認する。実機でも横スクロールと開閉を試す。先頭列固定は初期必須にせず、列幅を確保した試作で必要性を判断する。
- 着地: 醸成中。表示方式は合意、受け入れ基準と採用判断は未了。I-036 の分離を維持。


### 2026-09-20 — 方針確定・転記待ちへ

- 判断: ユーザーが提示した方針一式を承認。一般表の列幅確保、全状態の課題・アイデア一覧のカード化、補足開閉・検索・リンク維持、切り替え初期値 768px、単一の内容管理、全ページ機械確認と代表ページ・実機確認を確定した。
- 対象外: 計画書の構成改善 I-036、先頭列固定の初期導入、独自検索・絞り込み・並べ替え、開閉状態保存、配信変更、図・目次の全面改修。
- 詳細 HTML を新設し、現在の方針と転記下書きを移した。MD は原文と検討履歴を保持する。課題表を照合し、I-036 と並行運用ルールの I-030 は同梱しない。
- 着地: 待機。方針上の未決事項はなし。列幅などの具体値・実装方式は開発レーンの設計作業に委ねる。開発計画への転記後に採用とする。実装・ユーザー実機確認は未実施。
