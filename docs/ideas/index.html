4. 運用ルール（正）

4.1 アイデアの単位

  • 1 アイデア = 採用 / 見送りを 1 回で判断できる意思決定の単位。作業の単位ではない。リトマス試験:「このファイルにステータスを 1 つ付けられるか」
  • 入口はゆるく: 捕捉時は単位が曖昧でもよい。単位の整形は醸成の仕事
  • 分割は事後的に: 壁打ちの中で評価が割れたとき（一部は有望・一部は筋が悪い）、または前提が単独価値を持つと分かったときだけファイルを分ける。判定基準:「親アイデアを見送っても、これは単独でやる価値があるか」— Yes なら独立アイデア（相互リンク）、No なら親ファイル内の前提条件リストへ
  • 構想（kind: 構想）: 段階ごとに判断時期が異なる大きなアイデア（例: セット新設 → 他媒体展開 → アプリ化）。別の型ではなく「子を持つに至ったアイデア」。今判断できる段階だけ子として切り出し、後続段階は親の中に再検討トリガー付きで書く。子が採用されても親はクローズしない

4.2 ステータス（6 つ）

ステータス意思決定今動けるか条件の記載意味
inbox前○—書き留めただけ。壁打ち候補
醸成中前○—壁打ちを進められる
再醸成待ち前×必須（再検討トリガー）今はこれ以上詰められない。条件が満たされたら壁打ちを再開する（実行の約束ではなく再判断の約束）
待機済×必須（落とし込み条件）やると決めた。条件が満たされたら計画・戦略書へ転記する（開発レーンの作業）
採用済クローズ—計画・戦略書へステップとして展開済み（開発レーンならフェーズ内のステップ、セットレーンならセット計画書の進行中ステップ）。バックログへの課題行の追加は「展開」に当たらない — バックログはまだやると決まっていない課題の置き場であり、採用したもの（やると決めスコープも確定したもの）の置き場ではない。昇格先リンクを disposition に残す
見送り済クローズ—理由付きで残す。再検討時の出発点になる資産

4.3 ファイルの 2 層構造

  • 記録層（MD・唯一の正）: 1 アイデア 1 ファイル。ユーザーは殴り書きのまま話し、整形は Claude の仕事。「要旨」は Claude が毎回書き直す生きた要約、「原文メモ」「壁打ち記録」は追記のみ（書き換え禁止）。壁打ち記録は会話ログの貼り付けではなく、論点・判断・積み残しの蒸留
  • 閲覧層（HTML）: 本ページ（ダッシュボード）+ 深化したアイデアの詳細ページ <slug>.html。詳細ページを作ったら、整理された現在形（要旨・企画・構成図・スコープ等）はすべて HTML 側へ移し、MD の要旨はリンク 1 行に置き換える（同じ情報を 2 箇所に書かない）。MD に残るのは原文メモ・壁打ち記録・フロントマターのみ
  • 品質基準: 初見の人（数ヶ月後の自分・別セッション）が要旨（or 詳細 HTML）だけ読めば文脈を復元できること

4.4 壁打ちの終了規律

1 回の壁打ちは必ず次のいずれかに着地する。「なんとなく放置」を構造的に許さない。

  • まだ詰められる → 醸成中のまま
  • 今は無理 → 再醸成待ち（再検討トリガーを condition に記載）
  • 決めた → 待機（落とし込み条件を記載）or 採用 or 見送り（理由を記載）

着地とセットで: 壁打ち記録に蒸留を追記 → 要旨（or 詳細 HTML）を最新化 → 本ページの表を更新。壁打ち中に出てきた新アイデアはその場で inbox 捕捉し（醸成はしない）、本筋に戻る。セッションの成果 = テーマの着地 1 件 + 副産物の inbox 0〜n 件。

4.5 レーンと昇格

  • docs/ideas/ 配下で閉じる作業はアイデアレーン: 宣言不要・常に並行可（計画体系の判定表参照）
  • 採用時の展開先はレーンで決まる。開発レーン行きのもの（services/ shared/ infra/ database/・共通設計書に触れる）は development-plan.html / 事業戦略書へのステップ展開が必要で、これは開発レーンの作業 — アイデアレーン内では転記下書きの用意までとし、いったん待機で置く。セットレーンで完結するもの（content/<set>/ + セット別・専用方式設計書 + セット計画書）は、セット計画書の進行中ステップへその場で展開して採用まで進めてよい（セットレーンは常に並行可のため待機を挟む必要がない）。判定は計画体系セクション 2 のパス基準表に従う
  • 壁打ちで踏み込んだ技術検討（構成図・コスト試算）は採用判断のための検討記録であり設計書ではない。採用後は docs/app/ / docs/infra/ の設計プロセスにインプットとして引き継ぎ、そこで改めて設計 Fix する
