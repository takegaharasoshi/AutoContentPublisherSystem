本書の位置づけ（設計書に非ず） 収益化方針を決め直すための学習計画と情報源の選定記録。ここに書いた収益化手段の評価は暫定であり、事業戦略の正ではない。学びの反映先は 事業戦略書（収益化戦略・KPI）で、転記は開発レーン作業として別途行う。

1. 目的

「Meta のリール再生ボーナス一本」という収益化方針を、他の選択肢を知ったうえで決め直すための学習。

現在の 事業戦略書 セクション 2 は「まず運用開始」を最優先した当時の判断でボーナス一本に置いており、他の収益化手段を詳しく知らないまま決めている。当時の判断は正しかったが、複数セット（logic-training-1・pref-ranking-1）が稼働し始めた今が見直しの適期。

decision: 目的のピボット（2026-09-03） 当初の要旨「収益化戦略・KPI の精度を上げるインプット」から書き換えた。Claude は「M2（フォロワー転換）先行」を提案したが、ユーザーは「収益化手段を知らないまま決めた方針を見直したい」と判断し、こちらを採った。

2. 進め方

  • 担い手: 運用者本人が動画・有料コンテンツを視聴する。情報源の選定は Claude（Codex の Web リサーチ + 再検証）が行う。有料コンテンツは合計 3,000 円以内なら購入可
  • 学びの置き場: 視聴 1 本ごとに記録層 MD 末尾の視聴ログへ 1 行（日付・情報源・一言の学び）。要約や体系化の文書は作らない（負担が続かない）
  • 当てはめの捕捉: 「このプロジェクトにどう当てはめるか」が出たら /idea で inbox 捕捉し、本アイデアを親としてリンクする。学びは子アイデアとして蓄積される
  • 出口: 子アイデアがたまった時点で「収益化モデルの再決定」を事業戦略書へ反映する（開発レーンの転記作業）
  • ステータス運用: 学習はユーザー作業で、開発レーンのステップにはしない（ゴール対象になる作業がない）。墓場化防止のため再判断の期限を置き、期限で「戦略書を書き換えるか」を判断する。書き換えるなら待機（転記下書き付き）へ、続けるなら期限を切り直す

#手段内訳本プロジェクトとの相性（仮説）
①プラットフォーム支払いリール再生ボーナス（招待制）、サブスクリプション、ギフト（投げ銭）、ライブバッジボーナス・ギフトは顔なしでも成立。サブスク・ライブは人格前提で不利

④自社商品デジタル商品（note・Kindle）、物販（グッズ）、LINE 公式からの講座クイズ集・ランキング集のデジタル商品は候補。講座型は人格前提で不利
⑤アカウント周辺サービス運用代行、コンサル、アカウント売却自アカウントの収益化から遠い。売却は規約リスクがあり優先度低
⑥他プラットフォームの報酬YouTube ショート、TikTokplatform-expansion-tiktok と接続。AI 生成の「独自性」要件が論点

3.1 本プロジェクト固有の評価軸

一般論の動画は顔出し・人格のあるアカウントを前提にしがち。うちのアカウントは顔なし・自動運用・AI 生成なので、各手段を見るときに毎回この 3 点を当てる。

  1. (a) 顔なし・自動運用・AI 生成のアカウントで成立するか
  2. (b) クイズ・ランキングという既存ジャンルと商材が接続するか
  3. (c) 必要フォロワー規模と運用の手間が「生成 AI 定常費ゼロ・少人数」の予算方針と両立するか

4. 情報源の選定基準

  • A 実数を見せている: 収益額・再生数・フォロワー数のダッシュボードやスクショ、具体的な単価
  • B 一次情報: Meta 公式ヘルプ・公式クリエイター向けページ・公式発表
  • C 同ジャンルの事例: 顔なし・自動運用・AI 生成・雑学・クイズ・ランキング系
  • 除外: 高額商材への誘導が主目的の動画、根拠のない精神論中心の動画、2024 年以前で内容が古いもの（制度説明は 2025 年以降を優先）
選定の所見（2026-09-03） 日本語 YouTube の「インスタ収益化」は運用代行・講座販売への導線を持つ発信者が大半で、基準 A を検索結果だけで満たせる動画はなかった（尺・画面内の実数提示は未確認。視聴時に視聴ログへ書く）。基準 C の日本語動画は 1 本のみ。英語圏には「faceless theme page」という、うちのアカウント型そのものを指す概念と収益モデル（アフィリエイト先行・複数収益の重ね掛け）があるが、記事はツールベンダーの SEO が大半で数字は検証不能。

6. 論点と積み残し

  • 事業戦略書との整合: 戦略書には先行事例・競合・ベンチマークの節がなく、外部条件は「調査時点の目安」止まり。ボーナスは招待制・基準非公開で M3 は代理指標。他の収益手段の情報が入ると M3/M4 の置き方自体が変わりうる
  • 子アイデア候補: 2026-06 のリール商品タグのアフィリエイト対応は、pref-ranking-1 × 旅行・特産品アフィリエイトのような当てはめが考えられる。子アイデア化するかは視聴後にユーザーが判断する
  • 要確認: ギフトのフォロワー要件（5,000 か 500 か）をプロフェッショナルダッシュボードで確認する
