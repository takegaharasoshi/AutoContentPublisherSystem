### 2026-10-13

- 展開対象を **umigame-soup-1** に変更（ユーザー予想: 他プラットフォーム展開はウミガメで行うことになる）。コメント自動返信が必須のため、「どの面で返信が実現できるか」を最大の選定基準に格上げ
- 前提をユーザーと確定: 展開の形は**同じセット・同じ動画を複数プラットフォームへ**（世界観違いの複数アカウントとは組み合わせない）。返信は**数分おきのポーリングでも可**（Webhook の有無は除外理由にしない）
- Web 調査（公式ドキュメント優先・出典は詳細 HTML セクション 6）の結論: 実現しやすい順に Facebook リール（既存 Meta 基盤を流用）> YouTube Shorts（ポーリング・返信 約 200 件/日上限）> Threads > X（従量課金・月 50 ドル前後）> TikTok（法人登録・権限審査・投稿監査の 3 関門）。LINE VOOM・ニコニコは不可
- 判断: ウミガメの展開では事業戦略書 5 の「TikTok 第一候補」の根拠（動画の転用）が選定基準として弱くなり、**Facebook リールと YouTube Shorts が現実的な第一候補群**。戦略書の書き換えは採用時の転記で行う（今は触らない）。X 見送りの根拠（API 有料化）も従量課金化で前提が変わった可能性あり → 再開時に再評価
