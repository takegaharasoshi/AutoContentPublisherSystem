## 要旨

著作権が切れた作品（青空文庫など）を TTS で読み上げ、本文の文字組みとモーション（HTML / Three.js 等で生成）を映像にした「朗読アカウント」を新セットとして立てる案。
着想元は X の投稿（[aicreataro「凍った手記」](https://x.com/aicreataro/status/2107794785188864070)）: 物語と文字の動きを LLM（Opus 5.5）に書かせ、声は Gemini TTS、効果音は ffmpeg 合成、動画生成 AI は不使用。利点として「文字が崩れない・直しが速い・データが軽い」「Gemini TTS の演技はナレーションだと聞きやすい」が挙げられている。
本案は物語を自作せず既存のパブリックドメイン作品を読む点が違い、ストックの供給（作品選定・分割）が中心になる。
