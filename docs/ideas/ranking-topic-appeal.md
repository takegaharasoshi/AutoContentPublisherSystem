## 要旨

[[ranking-opening-hook]] の壁打ち（2026-08-28）で視聴維持カーブを 2 本比較したところ、
**冒頭の版面・タイミング・演出が完全に同一であるにもかかわらず、0:05 時点の維持率が
「ぎょうざ大好き都道府県」18% / 「ラーメン大好き都道府県」37% と 2 倍の差**がついていた。
コンポジションが同一である以上、差分は **ネタ / タイトル文言 / 背景イラスト**（+ 流入ソース構成の違い。
リールタブ 80.2% vs 70.2%）に限られる。

つまり冒頭離脱には、演出（動きの有無）とは別に **「ネタそのものの引き」という、おそらくより大きいレバー**がある疑い。
もしこれが確かなら、施策の主戦場はコンポジション改修ではなく**ネタ選定基準**（`/ranking-stock-replenish` の
ネタ選定ステップと WRITING-NOTES.md の勘所）になる。

壁打ちでは、サンプル数の確保、交絡（流入ソース構成・投稿日・アルゴリズムの機嫌）の切り分け、
「引きの強いネタ」を事前に見分ける基準を言語化できるか、が論点になる見込み。

## 前提条件・再検討トリガー

- サンプル数が 2 本では何も断定できない。**投稿実績が積み上がるのを待つ必要がある**
  （稼働開始 2026-08-27・1 日 1 投稿）。セット計画書のバックログ「テスト投稿・初速確認」（観測中）と同じ観測窓に乗る
- 視聴維持カーブは Graph API で取れずアプリ画面の目視のみ（16-6）。**手集計になるため、何本分を
  どう記録するかを決めないと壁打ちの材料が揃わない**
- [[ranking-opening-hook]] の冒頭改修を投入すると母集団が変わる。**改修の前後でネタ間のばらつきを比較しない**
  （改修日をセット記録に残すことが前提）
