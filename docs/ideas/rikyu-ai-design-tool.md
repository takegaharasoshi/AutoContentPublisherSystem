## 要旨

AI デザインツール **Rikyū**（https://rikyu.ai/ja）の利用を検討したい。
今すぐではなく、**サービスが発展してロゴなどのデザインが必要になったタイミング**での採用候補として捕捉しておく。

ツールの概要（2026-08-29 時点、公式サイトより）:
- 要件を文章で説明するだけで、ロゴ・Web サイト・SNS 素材まで一貫性のあるデザイン資産を自動生成
- 300 万点以上の素材ライブラリ（写真・動画）、PNG / SVG 書き出し
- **MCP 連携あり**（Claude などの AI アシスタントから呼べる）→ 本プロジェクトのバッチ生成パイプラインや Claude Code 運用と噛み合う可能性
- 料金: Free $0（個人利用のみ・初回 2,000 クレジット）／ Basic $5/月（商用可・1,200 クレジット）／ Pro $20/月 ／ Max $50/月

## 前提条件・再検討トリガー

- デザイン資産が実際に必要になること（アカウントのロゴ・アイコン・サムネイル雛形、あるいは将来の LP など）
