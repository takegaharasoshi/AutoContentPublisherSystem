## 要旨

umigame-soup-1（探偵カメロック）のコメント自動返信を、どこかのタイミングで**フォロワー限定**に切り替える。告知の建前は「大人気のため AI のコストがかさんだ」等。
フォロワー以外のコメントには、通常の Yes/No 回答の代わりに「フォローしてくれたら答える」旨の誘導コメントを返す。
狙いはフォロー転換（返信を参加特典にする）と返信コストの抑制。切替タイミング・告知の仕方・フォロー判定の技術的手段（API でコメント主のフォロー状態を取れるか）は未検討。
親: [ウミガメのスープ参加型アカウント](umigame-soup-set.md)

## 前提条件・再検討トリガー

- コメント主がフォロワーかどうかを Webhook / Graph API で判定できること（未確認）
- 切替は返信機能が定着し、コメント量が十分ある段階が前提（早すぎると参加の芽を摘む）

## 原文メモ

新しいアイデアです。

どこかのタイミングで「大人気のため、AIのコストなどがかさんだ」などという理由をつけて、ウミガメのスープのアカウントのコメント返信機能は、フォロワーの人にのみ返信する（フォロワー限定にする）ようにする。

フォロワー以外の人からのコメントについては、フォローしてほしい旨をコメントで返すようにする
