## 要旨

Claude Code への指示出し（特に壁打ち・レビュー所感・要件出しの長文）を音声で入力し、開発作業の入力速度を上げる。事業コンテンツではなく開発プロセス（作業環境）の改善アイデア。

壁打ち 1 巡目（2026-09-06）の現在の理解:

- **入力先は全部 Windows / スマホ側のアプリ**（VS Code 拡張のチャット欄・Windows Terminal 上の WSL CLI・スマホのブラウザ）。ディクテーションツールはカーソル位置にテキストを流し込むだけなので、WSL やリポジトリ側に何も足す必要はない
- **読み手が Claude（LLM）なので、整形品質より「専門用語の誤認識」と「パス・コマンド・識別子は発話できない」ことが実効性を決める**。音声は長文の発話向き、`/step 21-6` や sha 貼りのような短い定型はタイピングのまま、というハイブリッド運用が現実解
- **候補ツールの事実（2026-09-06 時点・Web 記事ベースで要再確認）**: Aqua Voice は Mac / Windows / iOS（2026-04〜）対応、Pro $8/月（年 $96）。ユーザーの過半が日本の開発者で「AI エージェントへの日本語入力の摩擦回避」が主用途という記事あり（動機がこのアイデアと同じ）。Typeless は Mac / Windows / iOS / Android 対応でスマホはカスタムキーボード方式。料金ページが非公開で医療向け案内になっているとの情報と、週 8,000 語の無料枠があるとの情報が混在。OS 標準（Windows の Win+H・iOS ディクテーション・Gboard）は無料
- **MVP は「無料の OS 標準で 1 週間、壁打ち・レビューの長文だけ音声にする」**。物足りなければ Aqua Voice の無料枠 → Pro で比較。作らないもの: 自作の音声パイプライン、Claude 側の対応

## 壁打ち記録

### 2026-09-06（1 巡目: Claude が観点 ③④⑤⑥⑦ を整理。ユーザー回答待ち）

**論点と Claude の見立て**

- ③ 既存資産との関係: 開発環境は Windows + WSL2、Claude Code は VS Code 拡張とローカル CLI、スマホは Tailscale 経由で設計書閲覧（docs-mobile-view）。ディクテーションはどの入力先にも OS レベルで挿入されるため、リポジトリ・スキル・設計書への変更はゼロ。音声が効く場面は「壁打ち」「ストック文言レビューの所感」「要件出し」の 3 つで、短い定型指示・sha 貼り・パス指定には効かない
- ④ 実現手段とコスト: 段階 0 = OS 標準（無料・即日）。段階 1 = Aqua Voice Pro $8/月（年 $96。iOS が別課金 $119/年という情報もあり要確認）または Typeless（料金情報が錯綜。要確認）。予算インパクトは軽微で、事業戦略書の予算枠とは別（開発者の作業環境費）
- ⑤ リスク: (a) 日本語の専門用語（CDK・Aurora・カメロック・ステップ番号）の誤認識。カスタム辞書の有無が選定基準になる。(b) 音声はクラウド送信。秘密情報を口にしなければ実害はないが、設計書の内容を読み上げることになる点は認識しておく。(c) 外出先の制約: 電車内など声を出せない場面が多く、「外出先 = スマホ = 音声」は成立しない可能性。「外出先で声が出せる場面（歩き・車・自室以外の個室）」に限られる。(d) 無料枠が切れたときの依存
- ⑥ MVP スコープ: Win+H（または iOS 標準）で 1 週間、長文だけ音声。効果があれば Aqua Voice 無料枠 → Pro で辞書・整形の差を比較。作らないもの: 自作パイプライン・Claude 側の対応・効果測定の仕組み
- ⑦ 採用判断に足りない情報 → 下記の質問

**判断**: 「Claude が読み手」である以上、整形の巧拙より誤認識と発話不能な入力（パス・識別子）の扱いが本質。有料ツールの価値は「日本語 + 専門用語辞書 + スマホ連携」に集約されるので、無料で試してから払う順番で損はない

**ユーザーへの質問（2 巡目の入口）**

1. スマホの OS（iOS / Android）と、スマホから Claude Code をどう操作しているか（Remote Control のブラウザ画面か、それ以外か）
2. 外出先で「声を出せる場面」はどのくらいあるか（歩き・車・カフェ・電車の比率感）
3. 今いちばん入力に時間がかかっているのはどれか: 壁打ちの長文 / レビュー所感 / 短い指示の連打
4. 2026-08-29 の原文メモにある「とかに」（「特に」の誤変換）は音声入力由来か。既に何かの音声入力を使っているなら、その精度の実感
5. Windows の Win+H（標準音声入力）を日本語で試したことがあるか

**積み残し**: 候補ツールの料金・スマホ対応の一次情報確認（公式サイト）、採用時の落とし込み先の決定
