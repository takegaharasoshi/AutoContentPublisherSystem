## 要旨

Claude Code への長文入力（壁打ち・レビュー所感・要件出し）を音声化して入力速度を上げる開発プロセス改善アイデア。**2026-09-06 に Typeless 無料版（週 8,000 語・1 アカウントで PC / スマホ共通）を導入して採用で着地**。

着地時点の整理:

- 入力先はすべて Windows / スマホ側のアプリ（VS Code 拡張・Windows Terminal の WSL CLI・スマホのブラウザ）で、リポジトリ・スキル・設計書への変更はゼロ
- 読み手が Claude なので、整形品質より「専門用語（CDK・Aurora・カメロック・ステップ番号）の誤認識」と「パス・コマンド・sha は発話できない」が本質。長文は音声、短い定型指示や貼り付けはタイピングのハイブリッド運用
- ツール選定は「試すコストがゼロ」の Typeless（30 日 Pro トライアル + 週 8,000 語の無料枠）から。有料化の比較対象は Aqua Voice Pro（$8/月・年 $96。Typeless Pro は $30/月・年 $144）

## 前提条件・再検討トリガー

- 同系統（開発プロセス改善）のアイデア: [claude-code-loop-goal-skills](claude-code-loop-goal-skills.md)（採用済み・Phase 19 へ展開）
- 落とし込み先: 計画書・設計書への転記なし（個人の作業環境）。Claude 側の含意は memory（`user_voice_input.md`）に記録
- 効果の測定は厳密にやらない（試用後の主観判断）
- **再検討トリガー**: 無料枠（週 8,000 語）が足りなくなったら、Typeless Pro（年 $144）と Aqua Voice Pro（年 $96）を日本語の専門用語辞書の効き方で比較して有料化を判断。専門用語の誤認識が目立つなら Typeless の個人辞書に登録する

## 壁打ち記録

### 2026-09-06（1 巡目: Claude が観点 ③④⑤⑥⑦ を整理。ユーザー回答待ち）

**論点と Claude の見立て**

- ③ 既存資産との関係: 開発環境は Windows + WSL2、Claude Code は VS Code 拡張とローカル CLI、スマホは Tailscale 経由で設計書閲覧（docs-mobile-view）。ディクテーションはどの入力先にも OS レベルで挿入されるため、リポジトリ・スキル・設計書への変更はゼロ。音声が効く場面は「壁打ち」「ストック文言レビューの所感」「要件出し」の 3 つで、短い定型指示・sha 貼り・パス指定には効かない
- ④ 実現手段とコスト: 段階 0 = OS 標準（無料・即日）。段階 1 = Aqua Voice Pro $8/月（年 $96。iOS が別課金 $119/年という情報もあり要確認）または Typeless（料金情報が錯綜。要確認）。予算インパクトは軽微で、事業戦略書の予算枠とは別（開発者の作業環境費）
- ⑤ リスク: (a) 日本語の専門用語（CDK・Aurora・カメロック・ステップ番号）の誤認識。カスタム辞書の有無が選定基準になる。(b) 音声はクラウド送信。秘密情報を口にしなければ実害はないが、設計書の内容を読み上げることになる点は認識しておく。(c) 外出先の制約: 電車内など声を出せない場面が多く、「外出先 = スマホ = 音声」は成立しない可能性。「外出先で声が出せる場面（歩き・車・自室以外の個室）」に限られる。(d) 無料枠が切れたときの依存
- ⑥ MVP スコープ: Win+H（または iOS 標準）で 1 週間、長文だけ音声。効果があれば Aqua Voice 無料枠 → Pro で辞書・整形の差を比較。作らないもの: 自作パイプライン・Claude 側の対応・効果測定の仕組み
- ⑦ 採用判断に足りない情報 → 下記の質問

**判断**: 「Claude が読み手」である以上、整形の巧拙より誤認識と発話不能な入力（パス・識別子）の扱いが本質。有料ツールの価値は「日本語 + 専門用語辞書 + スマホ連携」に集約されるので、無料で試してから払う順番で損はない

**ユーザーへの質問（2 巡目の入口）**

1. スマホの OS（iOS / Android）と、スマホから Claude Code をどう操作しているか（Remote Control のブラウザ画面か、それ以外か）
2. 外出先で「声を出せる場面」はどのくらいあるか（歩き・車・カフェ・電車の比率感）
3. 今いちばん入力に時間がかかっているのはどれか: 壁打ちの長文 / レビュー所感 / 短い指示の連打
4. 2026-08-29 の原文メモにある「とかに」（「特に」の誤変換）は音声入力由来か。既に何かの音声入力を使っているなら、その精度の実感
5. Windows の Win+H（標準音声入力）を日本語で試したことがあるか

**追記（同日・ユーザー質問への回答）**: Typeless は 1 契約で PC 版・スマホ版を共通利用できる（公式 help/billing「Pro access is available across devices」。同一アカウントで辞書・設定も端末間共有）。Pro は $30/月 または $144/年（月額と年額で約 2.5 倍差）。無料枠は週 8,000 語、アカウント作成時に Pro の 30 日トライアルがカード登録なしで自動開始。前回「料金ページ非公開」とした情報は古く、公式 pricing ページは現存する

**積み残し**: Aqua Voice の iOS 別課金の有無の一次情報確認、採用時の落とし込み先の決定

### 2026-09-06（着地: 採用）

- Typeless が 1 契約で PC・スマホ共通と分かった時点でユーザーが無料版を導入し、採用で着地。1 巡目の質問 5 件（スマホ OS・声を出せる場面の比率・入力のボトルネック・既存の音声入力経験・Win+H 経験）は回答不要となり閉じる
- 判断: 個人の作業環境の変更で、計画書・設計書に触れる要素がないため転記なし。「待機 → 採用」の開発レーン転記も不要
- Claude 側の運用上の含意を memory に記録: ユーザー入力に音声認識由来の誤変換（同音異義語・専門用語の取り違え）が混じりうるので、文脈で読み替えて確認は最小限にする
- 積み残し: 有料化判断（再検討トリガー参照）。Aqua Voice の iOS 別課金の一次情報確認は有料化の比較時に行えばよい
