トークン更新（配信面の機能 ④）

現行版 最終更新: 2026-10-24（31-2: 脳みそコーチの正解返信の返信用トークンも同じ方式で更新することを足した）。前回: 2026-10-18（Phase 30-3b で新設） 1 段上: 基本設計（全体）3 章 配信面の 5 系統

要約

トークン更新は、コメント自動返信が Instagram に返信するときに使う長期アクセストークンを、失効する前に自動で延ばす機能である。このトークンは 60 日で失効するため、週に 1 回 Lambda が新しいトークンを取り直し、同じ Secret に書き戻す。投稿に使うトークンはこの機能の対象外で、手動で更新する → 理由 D-01。

図 1 は、1 回の更新で何が起きるかを表す。Scheduler が Lambda を起こし、Lambda が Secret から今のトークンを読んで Instagram に更新を頼み、返ってきた新しいトークンを Secret に書き戻す。

項目要点
目的コメント返信用のトークンが失効して返信が全件止まるのを防ぐ
きっかけEventBridge Scheduler（毎週月曜 04:00 Asia/Tokyo）
入力Secret の ig_access_token
出力同じ Secret の ig_access_token と token_expires_at（新しい値に書き換え）
対象外投稿用のトークン（Secret acps/prod/{set_code}/sns/{platform}/{account_code}）は手動で更新する

1. きっかけ

更新は時刻だけで動く。本番面・ステージング面のそれぞれに、毎週月曜 04:00（Asia/Tokyo）のスケジュールが 1 本ずつある。Secret に手で入れた直後のトークンは Instagram の更新 API が受け付けないため、翌週の更新から延びる（条件は運用設計）。

2. 入力と出力

この機能が読み書きするのは Secret 1 つだけで、DB や S3 には触れない。

区分もの置き場所
読む今の長期トークン（ig_access_token）Secrets Manager acps/prod/umigame-soup-1/comment-reply（ステージング面は末尾に -staging）
呼ぶトークンの更新（grant_type=ig_refresh_token）Instagram（graph.instagram.com/refresh_access_token）
書く新しいトークンと有効期限（token_expires_at。UTC）同じ Secret（ほかのキーはそのまま）

3. 流れ

図 2 は、1 回の更新を時間の順に並べたもの。失敗した週は Secret を書き換えず、旧トークンがそのまま使われる（失効まで 60 日あるため、翌週の更新か手動実行で取り戻せる）。

4. 関わる部品

この機能はコメント自動返信と同じスタック・同じプログラムの中にある。

種類部品

D-01 コメント返信用のトークンだけを自動で更新する

決めたこと
コメント返信用（Instagram ログイン方式）の長期トークンは Lambda で毎週更新する。投稿用のトークンは手動更新とリマインドのまま
理由
返信用は 60 日の失効が実際に起きる方式で、失効すると返信が全件止まる。コメントの受信に合わせて更新する方式は、コメントが途絶えた期間に失効するため採らない
日付・出典
2026-10-11（Phase 21-6g）・課題 I-031。アプリ運用設計 5.4
