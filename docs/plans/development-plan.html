現状（2026-11-10 時点）: 3 本とも WaitForDbReady は Retry なし・Catch は States.ALL → HandleError。バッチ本体は States.TaskFailed / States.Timeout を 30 秒間隔・2 回・BackoffRate 2.0 でやり直している。HandleError の cause は 3 本とも「〜 batch task failed after retries」の固定文言。
