事業戦略書

現行版 最終更新: 2026-07-29 初版は 2026-07-23 の壁打ち（Phase 14-1）に基づく
本書の位置づけ 収益化戦略・予算・KPI・プラットフォーム展開方針など、システム設計より上位の事業意思決定の「正」。 システム設計書（docs/infra/・docs/app/）には事業論点を書かず、本書から参照する（体系ガイドのスコープガード）。 開発の進捗管理は従来どおり development-plan.md が担う。

1. 最終目標と基本戦略

  • 最終目標は収益化を狙った SNS 運用（A-1 壁打ち記録から継承）。いきなりの収益化は難しいため、段階を踏む
  • 基本戦略: 全自動運用の仕組みを土台に、セット（テーマ）のスクラップ&ビルドで当たりコンテンツを探索し、当たりを増幅する
  • 段階の整理:
    1. 仕組みの確立 — 完了（2026-07-22 に静止画で 1 日 3 回の全自動投稿の定常運用を開始）
    2. リーチ獲得能力の構築 — 完了（2026-07-26 に動画（リール）へ全面切替し 1 日 1 回の定常運用を開始。KPI M1）。収益化経路（セクション 2）の必要条件（Phase 14）
    3. 勝負セットの投入と探索 — 投入完了（2026-07-29 に logic-training-1 のリール + ストーリーズ実投稿が成功し、1 日 3 回の自動スケジュールを有効化）。リーチを狙う探索はここから（Phase 15〜16）
    4. 収益化・増幅 — 当たりの兆しが出たらプラットフォーム展開等で増幅（Phase 17）
優先順位の考え方（2026-07-23 壁打ち） 収益化のボトルネックは配信面の数ではなく「当たりコンテンツの発見」と「リーチ資産」。 プラットフォーム展開は増幅器であり、当たりがない状態で配信面を増やしても運用負荷だけが増える。 したがって「1 つのプラットフォーム（Instagram）で当たりの兆しを掴む → 横展開で増幅」の順とする。

2. 収益化経路

  • 本命: Meta 公式ボーナスプログラム（リール再生数等に応じた報酬）
  • 2026-07 時点の調査による特性（着手時に最新条件を再確認すること）:
    • 招待制（Meta 側から招待されるのを待つ形式。基準は非公開）・期間限定開催
    • 報酬水準の目安は 1 リール再生あたり約 0.03〜0.08 円。月数万円の収益にも 100 万再生規模が必要
  • 含意: この路線は「リールで大きなリーチを取れるアカウントを作る」こととほぼ同義であり、動画（リール）対応が最重要機能となる
リスク: 非オリジナルコンテンツ対策の強化 Meta は転載や「変換の少ない低労力 AI コンテンツ」をリーチ抑制・収益化プログラム除外の対象にする方針を強化している（2026-07 時点の調査）。 全自動 AI 投稿はこの対象に近い領域であるため、以下を必須要件とする:
  • 独自の世界観・スタイルの統一 — 一目でそのアカウントと分かる独自性を勝負セットのテーマ選定要件に含める（Phase 15）
  • AI 利用の開示 — キャプション等での開示方針を動画対応の設計（Phase 14）で具体化する
  • 他者コンテンツの転載・再利用型のコンテンツは扱わない
ボーナス一本足にしない構え KPI はアカウント資産（フォロワー・再生数）に置く。資産があれば現金化手段はボーナス以外（アフィリエイト・グッズ販売等）にも転用できるため、 ボーナスプログラムの制度変更リスクに事業全体が引きずられない。

3. 予算

  • 月額上限 2 万円（AWS 利用料 + 生成 AI API 利用料 + その他固定費の合計）
  • 探索期（収益ゼロの期間）は月額固定費（サブスク・有料 API プラン）を原則積まない。従量課金を基本とする（X API を当面見送る根拠。セクション 5）

第 3 セット pref-ranking-1 の生成費（Remotion + TTS + イラスト） 0 円（2026-08-10、17-1 で確定） 動画は Remotion のローカル事前ビルド（quiz-prebuilt と同型の作り置き）、ナレーション TTS は VOICEVOX（無料・商用可・ローカル Docker 実行。クレジット表記「VOICEVOX:白上虎太郎」をキャプション常設）、キャラ・背景イラストは Codex 組み込み imagegen（サブスク内）。有料サブスク型 TTS（ElevenLabs 等）は「探索期は月額固定費を積まない」原則（15-4 の Suno 見送りと同じ）により不採用（17-1 壁打ち記録）
音源（リール用 BGM） 初期 0 円（CC0・フリーライセンス音源） 段階方式（2026-07-23 の 14-2 壁打ちで決定）: 検証用セットは CC0/フリー音源、勝負セット投入時に AI 音楽生成（Suno 等・$10/月程度を 1 か月だけ契約しストック生成 = 単発費用）への格上げを検討。詳細は 14-2 壁打ち記録。 → 2026-07-26（15-4 壁打ち）で決着: 勝負セット logic-training-1 も CC0/フリー音源の継続を決定（格上げ見送り・0 円維持。BGM に加え効果音〔SE〕も CC0 で調達。M2 の手応えを見て格上げの再検討余地は残す。15-4 壁打ち記録）
予算の主ダイヤル コストを支配するのは動画の「本数 × 長さ × 画質」と生成方式の選択。 初期値は「1 日 1 本・10 秒前後・標準画質」とし（2026-07-23 壁打ちで合意）、KPI とコスト実績を見て調整する。 勝負セット logic-training-1 の方式（gpt-quiz-multicut）は LLM テキスト + 情景イラスト 1 枚（medium）で 1 本あたり十数円と単価が低く、本数を増やしてもコストへの感度が小さいため、例外として「1 日 3 回・20 秒」で開始する（2026-07-26 の 15-4 壁打ちで決定。コスト内訳は上表 — 15-9 のイラスト採用で「LLM テキストのみで月数十円以下」の当初想定から改訂）。その後、16-1 のテコ入れ（2026-08-01。生成チェーン休止・尺は 16 秒へ変更）と 16-3b の動画事前生成転換（2026-08-08。現行方式は quiz-prebuilt）により、logic-training-1 の生成 AI API 定常費は完全にゼロとなった（残る変動費は AWS 基盤のみ。事前生成のイラストは Codex サブスク内の imagegen で賄う）。 動画生成 API は移り変わりが激しいため、特定サービスに固定せず方式差し替え可能な構造（generator strategy）を維持する。
