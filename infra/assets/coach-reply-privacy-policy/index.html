プライバシーポリシー

Instagram アカウント「脳みそコーチ」の正解コメントへの自動返信について
制定日: 2026 年 10 月 24 日

本アカウントの運営者（以下「運営者」）は、投稿への正解コメントに「脳みそコーチ」が定型文で返信するための専用アプリ（以下「本サービス」）で扱う情報を、このポリシーに従って取り扱います。

1. 取得する情報

本サービスは、Instagram（Meta Platforms, Inc.）の API を通じて、本アカウントの投稿と、その投稿に付いたコメントを読み取ります。

  • 投稿の ID・投稿日時・コメント数
  • コメントの本文・コメント ID・投稿日時・投稿者のユーザーネーム、および既存の返信（判定対象の選別と運営者による返信の確認のため）

コメント本文とコメントした人の名前（氏名・ユーザーネーム）は保存しません。プロフィール・フォロワー・いいね等の情報は取得しません。

2. 利用目的と書き込む情報

  • コメントが投稿した問題の正解に当たるかを判定するため
  • 正解と高い確信で判定できたコメントに、定型文の返信を送信するため
  • 同じコメントへの重複返信を防ぎ、判定・返信の状況を確認するため

Instagram に書き込むのは、正解コメントに対する返信です。広告配信・販売・第三者へのマーケティング目的には利用しません。

3. 外部サービスへの送信

正解かどうかを判定するため、コメント本文・コメント ID と、出題した問題・正解・解説等を、AI サービスの提供事業者 Anthropic, PBC の API に送信します。コメントした人の名前・ユーザーネームは AI サービスへ送信しません。

コメント ID と判定の結果、返信済みかどうか等の運用記録は Amazon Web Services（Amazon Web Services, Inc.）のクラウド上に保存します。法令に基づく場合を除き、これ以外の第三者に提供しません。

4. 保存する情報と保存期間

保存するのは、コメント ID と判定の結果（判定・確信度・短い理由）、判定日時、返信の有無・返信 ID、および投稿ごとの処理状況です。コメント本文とコメントした人の名前は保存しません。

重複返信を防ぐため、判定済みの記録は本サービスの運用に必要な期間保存します。返信として Instagram 上に投稿した文章は、本アカウントの投稿へのコメントとして Instagram 上に残ります。

5. データの削除・お問い合わせ

ご自身のコメントに関する記録の削除をご希望の場合や、このポリシーについてのお問い合わせは、Instagram で @umigame.soup.jp へダイレクトメッセージをお送りください。削除のご依頼は、対象のコメント（投稿とおおよその日時）をお知らせいただければ、受け付けから 30 日以内に記録を削除し、その旨をご連絡します。

Instagram 上でコメントを削除しても、本サービスの記録は自動では削除されません。必要な場合は上記の方法でご連絡ください。

6. ポリシーの変更

このポリシーは、必要に応じて改定することがあります。改定した場合は、このページの内容と制定日（改定日）を更新します。

Summary in English

The Instagram account “脳みそコーチ” uses a dedicated app to read comments on its posts and send fixed replies to answers judged correct with high confidence. Comment text, comment IDs and puzzle information are sent to Anthropic for judgment; commenter names and usernames are not sent. Comment IDs, judgment results and reply status are stored on Amazon Web Services for as long as needed to operate the service and prevent duplicate replies. Comment text and commenter names are not stored. To request deletion, send a direct message to @umigame.soup.jp on Instagram; we will delete the records within 30 days.
