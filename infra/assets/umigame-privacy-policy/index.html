プライバシーポリシー

Instagram アカウント「コメントで推理！探偵カメロックのウミガメのスープ」（@umigame.soup.jp）のコメント自動返信について
制定日: 2026 年 10 月 12 日

本アカウントの運営者（以下「運営者」）は、投稿へのコメントに出題者「探偵カメロック」が自動で返信する仕組み（以下「本サービス」）で扱う情報を、このポリシーに従って取り扱います。

1. 取得する情報

本サービスは、Instagram（Meta Platforms, Inc.）の API を通じて、本アカウントの投稿に付いたコメントについて次の情報を受け取り、記録します。

  • コメントの本文・コメント ID・コメントが付いた投稿の ID・返信先のコメント ID
  • コメントした人の ID（Instagram が本サービス向けに発行する識別子）。ユーザーネーム・プロフィール・フォロワー等の情報は保存しません
  • コメントの受信日時、本サービスが作った返信の本文と送信日時、判定の結果（「はい / いいえ / 関係ない」等）

本アカウントへの投稿・フォロー・いいね等の情報は、本サービスでは取得しません。

2. 利用目的

  • コメントの質問に対する返信を自動で作り、送信するため
  • 判定や返信の誤りを見つけ、品質を改善するため
  • 不正な利用・迷惑行為への対応のため

広告配信・販売・第三者へのマーケティング目的には利用しません。

3. 外部サービスへの送信

返信を作るため、コメントの本文と出題中の問題の情報を、AI サービスの提供事業者（Anthropic, PBC および OpenAI, L.L.C.）の API に送信します。送信した情報は各社の API 利用規約に基づいて処理され、各社の規約では API 経由のデータは既定でモデルの学習に使われないとされています。コメントした人の ID は AI サービスへ送信しません。

記録は Amazon Web Services（Amazon Web Services, Inc.）のクラウド上に保存します。法令に基づく場合を除き、これ以外の第三者に提供しません。

4. 保存期間

記録は取得から最長 1 年保存し、その後削除します。返信として Instagram 上に投稿した文章は、本アカウントの投稿へのコメントとして Instagram 上に残ります。

5. データの削除・お問い合わせ

ご自身のコメントに関する記録の削除をご希望の場合や、このポリシーについてのお問い合わせは、Instagram で @umigame.soup.jp へダイレクトメッセージをお送りください。削除のご依頼は、対象のコメント（投稿とおおよその日時）をお知らせいただければ、受け付けから 30 日以内に記録を削除し、その旨をご連絡します。

Instagram 上でコメントを削除しても、本サービスの記録は自動では削除されません。必要な場合は上記の方法でご連絡ください。

6. ポリシーの変更

このポリシーは、必要に応じて改定することがあります。改定した場合は、このページの内容と制定日（改定日）を更新します。

Summary in English

The Instagram account @umigame.soup.jp automatically replies to comments on its posts. To do so, it receives the comment text, comment / media IDs and the app-scoped ID of the commenter through the Instagram API (usernames and profile data are not stored). Comment text and the current puzzle are sent to AI providers (Anthropic and OpenAI) to generate replies; commenter IDs are not sent. Records are stored on Amazon Web Services for up to one year and are used only to reply and to improve reply quality. To request deletion of your data, send a direct message to @umigame.soup.jp on Instagram; we will delete the records within 30 days.
